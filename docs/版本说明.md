# Observer_Motor 版本说明

## 2026-09-26：单脉冲电感辨识 V10

### 本版内容

- 新增 `ls_identify` 单脉冲电感辨识命令及 `ls_identify dump` 原始 ADC 数据导出。
- Ls 辨识必须先在同一上电周期成功执行 `rs_identify`，使用本次实测相电阻；未测得时拒绝注入。
- 通过 TIM1 单脉冲产生 60 μs A-B 电压阶跃，ADC2 以 500 kSPS 采样 256 点，分别拟合升流与续流衰减段。
- 增加 PWM 引脚状态、ADC 越界/超限、外设恢复状态诊断；结束或异常时关闭功率输出并恢复 ADC/TIM1。
- 修正 Rs/Ls 连续运行时 TIM1 单脉冲模式残留导致的 Rs ADC 停滞问题。
- 观测器单相电阻配置更新为 3.34 Ω；当前 `Ls=0.00086 H`（860 μH）配置保留。

### 调试过程记录

1. **发现初始采样没有有效电流响应。** V2/V3 结果只有 0～1 个升流样本，ADC 原始码接近零电流偏置。TIM1 引脚诊断显示预充电和脉冲中点状态不符合预期，因此先定位 PWM 输出和采样路径，没有把无效结果当作电感值。
2. **确认下桥臂采样和续流状态。** V4 将脉冲提高至 14 μs 后观察到电流变化，但升流/衰减拟合分别为 770/343 μH，结果不一致。V5 将脉冲改为 60 μs，采到 28 个升流点和 206 个衰减点，候选值仍为 848/435 μH，拟合质量检查正确拒绝了该结果。
3. **以实测电阻替代估算值。** 串口 `rs_identify` 得到约 3.66～3.75 Ω；Ls 命令改为只接受同一上电周期实测 Rs。期间 V6/V7 引脚记录发现续流时 `PINS=4`、`CCER=0x54`，U 下管输出未保持。
4. **修正续流 PWM 通道控制。** V8 不再清除 `CC1E`，改为将 CH1 比较输出强制为 inactive，同时保留 CH1/CH1N 和 CH2/CH2N 使能。实机续流检查恢复为 `PINS=6`，四次 Ls 拟合均有效。
5. **修复重复运行 Rs 时的 ADC 停滞。** V8 后连续运行中再次执行 Rs 会报 `ADC_STALL`。V9 保存并恢复 ADC 注入序列等配置后问题仍在；SWD 读到 TIM1 `CR1=0xA8`，确认 OPM 位残留。V10 在 TIM1 恢复时清除 OPM 并核对状态。
6. **V10 同一上电周期实机复测。** COM27、2,000,000 baud，按 `rs_identify → ls_identify → rs_identify → ls_identify` 执行，四步均成功，最后 `TIM1_CR1=0xA0`（OPM=0）。Rs 为 3.821311 Ω、3.741168 Ω；两次 Ls 上升段为 806.298、815.223 μH，衰减段为 973.823、964.066 μH，均 `FIT_VALID=1`、`FREEWHEEL_DIAG PINS=6`，无 ADC overrun 或软件过流标志。

### 使用与验证边界

串口先执行 `rs_identify`，等待 `RS_IDENTIFY DONE Rs=... ohm`，然后执行 `ls_identify`。结果必须是 `RS_SOURCE=MEASURED` 且 `FIT_VALID=1` 才可采用。V8 四次和 V10 两次共六次有效辨识的候选值平均约 860.6 μH，范围 806.3～973.8 μH；该结果支持当前约 0.86 mH 的配置，但不是高精度标定。

现有验证包括 Release 固件构建、VS Code/OpenOCD 烧录验证、COM27 实机串口重复辨识，以及 MCU PWM 引脚、ADC 波形和外设恢复检查。绕组实际差分电压仍以 Vbus 近似，MOS 栅极波形和软件 ADC 看门狗的实际关断延迟尚未通过示波器验证；本模块的软件过流处理不等同于独立硬件过流保护。完整参数、状态码与限制见 [Ls 辨识状态记录](LS_IDENTIFY_STATUS.md)。
