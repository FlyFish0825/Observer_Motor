# Observer_Motor 版本说明

## V1｜电机参数辨识

**【新增功能】** 本版本首次整理发布电机定子电阻（Rs）和单脉冲电感（Ls）辨识功能。

- 串口命令 `rs_identify` 使用四档定电压注入辨识 Rs；CAN 支持 `MOTOR_IDENTIFY (0x12)` 启动、停止及结果反馈，并保留串口定电流对照命令 `rs_identify current`。
- 串口命令 `ls_identify` 使用 TIM1 单脉冲和 ADC2 采样，分别拟合升流段与续流衰减段。运行前须在同一上电周期成功测得 Rs；未测得时拒绝注入。
- 增加 PWM 引脚、ADC 越界/超限和外设恢复诊断；结束或异常时关闭功率输出并恢复 ADC/TIM1。
- 修复连续运行 Rs/Ls 时单脉冲模式残留造成的 ADC 停滞问题，并合并、精简辨识实现。

**验证记录：** 已完成 Release 构建、OpenOCD 烧录和 COM27 串口重复辨识。六次有效 Ls 测试候选值约为 806～974 μH，支持当前约 0.86 mH 配置，但不代表高精度标定。MOS 栅极波形、实际绕组差分电压和软件过流关断延迟仍需示波器验证。

辨识功能的开发过程中包含多轮参数与故障诊断测试；这些测试轮次不是独立软件版本。详细实现、测试数据、使用步骤和限制见 [Ls 辨识状态记录](LS_IDENTIFY_STATUS.md)。
