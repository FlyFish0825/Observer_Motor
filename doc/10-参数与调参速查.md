## 1. 量纲与单位约定

整个工程只有一套单位制，混用时最容易出错的是"电"与"机械"两类角度/转速。

| 物理量 | 单位 | 说明 |
|---|---|---|
| 电流 | A | 相电流峰值，不是有效值 |
| 电压 | V | 相电压瞬时值；母线电压也是 V |
| 电阻 | Ω | 定子相电阻 |
| 电感 | H | α/β 两轴共用同一值（表贴式近似） |
| 磁链 | Wb | 永磁磁链幅值 |
| 电角度 | rad | `theta_ctrl`、`virtual_angle`、磁链 atan2 输出 |
| 机械角度 | rad | 只在极少数显示路径出现 |
| 电角速度 | rad/s | `pll_omega_e` |
| 机械转速 | rpm | `speed_rpm`、`speed_ref_rpm`、控制台 `speed` |
| 时间 | s | `Ts`、`sample_time` |
| 频率 | Hz | PWM 载波、滤波器截止 |
| 增益（电流环） | V/A、V/(A·s) | 输入 A、输出 V |
| 增益（速度环） | A/rpm、A/(rpm·s) | 输入 rpm、输出 A |
| 斜坡 | rpm/s、A/s、rad/s² | 速度参考、Iq 参考、虚拟角加速度 |

### 1.1 电与机械的换算

```
电角度   = 机械角度 × 极对数
电角速度 = 机械转速(rpm) × 极对数 × 2π / 60
机械转速(rpm) = 电角速度(rad/s) × 60 / (2π × 极对数)
```

当前极对数 `pole_pairs = 7`。常用换算：

| 机械转速 | 机械角速度 | 电角速度 |
|---|---|---|
| 1000 rpm | 104.72 rad/s | 733.04 rad/s |
| 1500 rpm | 157.08 rad/s | 1099.56 rad/s |
| 3000 rpm | 314.16 rad/s | 2199.11 rad/s |

角加速度换算是这里最容易搞混的一处，因为**机械角加速度与电角加速度差一个极对数**：

```
机械角加速度 α_m [rad/s²]  →  d(n)/dt [rpm/s] = α_m × 60/(2π) ≈ α_m × 9.5493
电角加速度   α_e [rad/s²]  →  d(n)/dt [rpm/s] = α_e × 60/(2π×p) ≈ α_e × 1.3644   (p = 7)
```

| 输入 | 类型 | 折算结果 |
|---|---|---|
| 10 rad/s² | 机械 | ≈ 95.493 rpm/s |
| 10 rad/s² | 电角（p=7） | ≈ 13.644 rpm/s |
| 600 rad/s² | 电角（p=7） | ≈ 818.5 rpm/s |

> 两处文档用的是不同口径，读的时候要看清楚：
> - [08 启动修正](08-双向静止启动与平滑接管修正.md)里"10 rad/s² 对应约 95.493 rpm/s"说的是**机械**角加速度；
> - `MOTOR_APP_IF_ACCEL_RAD_S2 = 600`（`Core/Src/motor_app.c:75`）是**电角**加速度，折算机械约 `600 × 1.3644 ≈ 818.5 rpm/s`，源码注释写作"约 819 rpm/s"。
> - I/F 拖动使用同一个速率换算（`Core/Src/motor_app.c` 中虚拟角爬升处）。

## 2. 节拍、分频与时间阈值

| 量 | 值 | 位置 | 说明 |
|---|---|---|---|
| PWM 载波 / 电流环节拍 | 25 kHz（Ts = 40 µs） | `Core/Src/motor_app.c:50`、`foc_math.c:44` | TIM1 中心对齐，ARR=3399 → `(3399+1)*2/170 MHz = 40 µs` |
| 控制中断 | 25 kHz | ADC1 JEOS | `MotorApp_OnInjectedConversion()` |
| 速度环 | 1 kHz | `FOC_SPEED_LOOP_DIVIDER_DEFAULT = 25` | 25 kHz / 25 |
| CAN 调度 tick | 1 ms（TIM6） | `motor_protocol.c` | 时隙计数基准 |
| CAN 调试反馈 | 2 ms | `MOTOR_PROTOCOL_DEBUG_DIVIDER = 2` | 每 2 个 tick |
| 波形（justfloat）抽样 | 1 kHz | `motor_app.c` | 帧长约 180 µs，忙则丢弃 |

`MOTOR_APP_CONTROL_HZ` 是**所有毫秒阈值折算成中断计数的基准**。改 TIM1 的 ARR 或时钟树时，必须同步改它，否则 `MOTOR_APP_MS_TO_TICKS()` 算出的所有启动超时都会按错误节拍计时。

### 4.3 电流环与电压限幅（`Core/Inc/controller.h`）

| 符号 | 默认值 | 单位 | 作用 |
|---|---|---|---|
| `FOC_ID_PI_KP_DEFAULT` | 0.220 | V/A | d 轴电流环 Kp |
| `FOC_ID_PI_KI_DEFAULT` | 1257.0 | V/(A·s) | d 轴电流环 Ki；每拍增量 ≈ `0.0503 × error` |
| `FOC_IQ_PI_KP_DEFAULT` | 0.220 | V/A | q 轴电流环 Kp（表贴式 Ld≈Lq，同值） |
| `FOC_IQ_PI_KI_DEFAULT` | 1257.0 | V/(A·s) | q 轴电流环 Ki |
| `FOC_VOLTAGE_UTILIZATION_DEFAULT` | 1.0 | — | 电压利用率；1.0 表示用满线性 SVPWM 区 |
| `FOC_INV_SQRT3_DEFAULT` | 0.57735026919 | — | 1/√3，用于 `voltage_limit = Vbus/√3` |

设计依据（源码注释）：电机电气时间常数 `L/R = 100 µH / 0.5 Ω = 200 µs`，是开关周期 40 µs 的 5 倍，属"电流环带宽远高于被控对象"的常规配置，故取比例主导、积分中等的保守值。

调参方向：
- 调大 Kp：电流阶跃变快，但死区非线性与采样噪声被放大成高频振荡。
- 调大 Ki：静差收敛快，过大时与电压限幅耦合产生低频摆动甚至极限环。
- 改 `FOC_VOLTAGE_UTILIZATION_DEFAULT`：调低会主动降低可用电压与最高转速；调高超过 1.0 进入过调制，本工程不做。

## 5. 调参前的固定检查

改任何一个数字前，先确认没有踩到下面这些**耦合关系**：

| 改动 | 必须同步 | 后果 |
|---|---|---|
| TIM1 ARR / 时钟树 | `MOTOR_APP_CONTROL_HZ`、`foc.timer.pwm_arr`、`Ts`、所有 ms 阈值 | 全部时间阈值按错误节拍计时 |
| `speed_loop_divider` | `PI_Controller_SetSampleTime()` | 速度环积分强度按分频比成比例偏离 |
| `adc.c` 注入通道 | `MOTOR_APP_ADC*_INJ_*` | 上电自检拒绝启动 |
| `pole_pairs` | 显示/换算路径 | 观测器角度换算处**未读取**该字段（见 §7） |
| `flux_linkage` | `psi_min` / `psi_max` / Ready 磁链门限 | 判据区间与真实磁链不匹配 |
| 电机本体更换 | `Rs`、`Ls`、`flux_linkage`、`pole_pairs`、电流增益 | 观测器与电流标定全部失配 |

## 6. 危险参数清单

下列参数改动会**直接影响功率级输出或保护判据**，建议只在断电、空载、限流的条件下调整，并保留回退点：

1. `vbus`（可写）：同时影响 SVPWM 定标和 dq 电压限幅，写错会让实际输出电压与期望不符。
2. `iq`、`id`（可写）：直接进入电流环给定，过量会导致过流。
3. `speed`：±15000 rpm 范围内可写，实际可达转速受电压与负载限制。
4. `FOC_SPEED_PI_OUTPUT_*_DEFAULT`：软件限幅，**不是**硬件过流保护。
5. `FOC_VOLTAGE_UTILIZATION_DEFAULT`：>1.0 进入过调制，本工程不承诺行为。
6. `MOTOR_APP_ALIGN_ID_A`、`MOTOR_APP_IF_IQ_A`：定位/拖动电流，长期偏大会发热。
7. `MOTOR_APP_START_TOTAL_TIME_MS`：调得过大会让开环发热时间变长。
8. `dead_time`：太小会直通，太大会明显畸变电流。
9. `adc_chk = 0`：绕过注入序列自检，采样通道是否可信需自行判断。
10. `gain_a/b/c`：电流标定系数，错一个量级会导致过流或失控。

## 7. 已知注意点与历史结论

这些是源码注释里点明、但容易在调参时忽略的事实：

1. **观测器角度换算处不读 `pole_pairs`**（`Core/Inc/observer.h:32`）：改极对数不会自动改变该处换算，需人工核对。
2. `Observer_MotorParam_t.pole_pairs` 的类型是 `uint8_t`，而多数换算路径用 `float` 转换后参与运算。
3. `foc_sin_cos` 当前未使用，是预留缓存（`Core/Inc/foc_math.h`）。
4. `Observer_State_t.pll_phase_` 是预留角度补偿字段，当前观测流程未更新（`Core/Inc/observer.h:173`）。
5. `FOC_Control_t.iq_ref` 上电默认 **0.20 A**（不是 0），保留一点转矩电流用于建立可观测的端电压。
6. `speed_slew = 0` 是"冻结参考"而非"最快"，它与"不限制"是两种完全不同的语义。
7. `MOTOR_APP_CLOSED_LOOP_HEALTH_ENABLE = 0`：当前台架策略不因高速电流误差自动停机，相关门限宏保留但未生效。
8. `MOTOR_APP_OBSERVER_READY_ANGLE_CHECK_ENABLE = 0`：绝对负载角判据关闭（I/F 固有负载角在重载下会误杀）。
