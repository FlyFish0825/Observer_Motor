## ADC 采样架构

### 两组通道，职责分离

| 组 | 触发 | 通道 | 用途 | 频率 | 中断 |
|----|------|------|------|------|------|
| **注入组** | TIM1 CH4 硬件触发（中心对齐顶点） | ADC1 R1 (U电流), ADC2 R1 (V电流), ADC1 R2 (W电流) | 电流环 | 25 kHz | ADC1 JEOS |
| **规则组** | 主循环软件触发（间断模式） | ADC1 R0 (母线), R1 (U端), R2 (W端); ADC2 R0 (V端) | 电压观测 | ~1 kHz | 无 |

### 为什么分两组

1. **同步要求不同**：注入组必须与 PWM 严格同步（中心对齐采样避开开关瞬态），只能硬件触发；规则组不需要同步，软件触发即可。
2. **频率不同**：电流环 25 kHz 必须精确；电压观测 ~1 kHz 足够。
3. **中断隔离**：注入组 JEOS 产生控制中断（最高优先级）；规则组不开中断，主循环轮询，避免中断嵌套。
4. **共用中断向量**：ADC1_2 是共享向量，但只有 ADC1 JEOS 触发回调；ADC2 注入组不开中断，结果在 ADC1 回调中统一读取。

### 注入组时序

```
TIM1 中心对齐计数:
  0 ─────────── 3399 ─────────── 0
                ↑
          CCR4 = 3398
          → ADC 注入触发
          → ADC1: Rank1(U) → Rank2(W)  顺序转换
          → ADC2: Rank1(V)             同步转换
          → 全部完成 → JEOS 中断
          → MotorApp_OnInjectedConversion()

采样时刻 = 载波顶点附近
低侧 MOSFET 刚关断 → 分流电阻电流稳定 → 采样准确
```

### 规则组时序（间断模式）

```
主循环 BoardAdc_Update():
  for rank = 0, 1, 2:
    HAL_ADC_Start(&hadc1)           ← 软件触发当前 Rank
    HAL_ADC_PollForConversion(10ms) ← 等待完成
    values[rank] = HAL_ADC_GetValue ← 读 DR

  HAL_ADC_Start(&hadc2)             ← V 相
  HAL_ADC_PollForConversion(10ms)
  v_raw = HAL_ADC_GetValue(&hadc2)
```

- **间断模式**：每次 `HAL_ADC_Start` 只转换一个 Rank，读完再触发下一个
- 为什么不用连续扫描：6.5 T 转换时间下，3 个 Rank 连续扫描 ~20 μs，HAL 轮询来不及逐通道读 DR
- 每通道超时 10 ms，总最坏 ~40 ms（实际 < 100 μs）

## 电流采样链路

### 硬件电路

```
电机 U 相 ──→ 5 mΩ 分流电阻 ──→ 内部 OPAMP1 (×24 增益) ──→ 1.65 V 偏置 ──→ PA1/ADC1_IN1
电机 V 相 ──→ 5 mΩ 分流电阻 ──→ 内部 OPAMP2 (×24 增益) ──→ 1.65 V 偏置 ──→ PC1/ADC2_IN1
电机 W 相 ──→ 5 mΩ 分流电阻 ──→ 内部 OPAMP3 (×24 增益) ──→ 1.65 V 偏置 ──→ PA3/ADC1_IN3
```

### 电气参数

| 参数 | 值 | 计算 |
|------|-----|------|
| 分流电阻 | 5 mΩ | 硬件 |
| 运放增益 | ×24 | 内部 OPAMP 配置 |
| 中点偏置 | 1.65 V | 3.3/2，双向测量 |
| ADC 参考 | 3.3 V | VREF+ |
| ADC 分辨率 | 12 位 | 4096 码 |
| 每码电压 | 3.3/4096 ≈ 0.806 mV | |
| 每码电流 | 0.806mV / (5mΩ×24) = **0.0067138671875 A** | |
| 零偏计数（0 A） | 2048 | 1.65 V ÷ (3.3/4096) |
| 满量程电流 | ±13.75 A | (3.3−1.65)/(0.005×24)，即 ±1.65 V 摆幅 |

换算示例（gain = 0.0067138671875 A/计数）：

```
1 A   → 压降 5 mV × 24 = 120 mV → 1.65+0.12 = 1.77 V → ADC ≈ 2207
-1 A  → 1.65 − 0.12 = 1.53 V                  → ADC ≈ 1889
10 A  → 1.65 + 1.20 = 2.85 V                  → ADC ≈ 3546
-10 A → 1.65 − 1.20 = 0.45 V                  → ADC ≈  550
±13.75 A（满量程）→ 3.3 V / 0 V             → ADC ≈ 4095 / 0
```

### 电流换算公式

```
i = (offset - raw) × gain

offset: 零偏 ADC 计数（校准平均值，理想 2048）
raw:    当前 ADC 计数
gain:   0.0067138671875 A/计数

正方向: raw < offset → i > 0（电流流入电机）
负方向: raw > offset → i < 0（电流流出电机）
```

### 零偏校准

| 步骤 | 说明 |
|------|------|
| 前提 | 功率桥关闭（MOE=0），无相电流，分流电阻两端等电位 |
| 触发 | 上电后 ADC1 注入组启动，TIM1 CH4 开始触发 |
| 持续 | 前 1000 拍（~40 ms） |
| 方法 | 累加 3 个 JDR 寄存器，最后除以 1000 取平均 |
| 结果 | `foc.calibration.ia/ib/ic_offset` = 零电流时的平均 ADC 计数 |
| 标志 | `foc.calibration.calibrated = 1` |
| 校准期间 | 不跑闭环，不写 CCR，只累加计数 |

### 高占空比重构

| 条件 | 重构相 | 公式 | 原因 |
|------|--------|------|------|
| CCR_A 最大且 > 3229 (95%) | A 相 | `Ia = -Ib - Ic` | 低侧导通仅 5%×40μs=2μs，采样不可靠 |
| CCR_B 最大且 > 3229 | B 相 | `Ib = -Ia - Ic` | 同上 |
| CCR_C 最大且 > 3229 | C 相 | `Ic = -Ia - Ib` | 同上 |

- 阈值 = 3399 × 95/100 = 3229（整数，`FOC_Data_Init` 中计算一次）
- 重构相的电流**覆盖**直接换算值
- 另外两相的采样仍然有效（它们的占空比 < 95%）

## 端电压融合

### 硬件电路

```
U 相端电压 (PB12) ←── 100kΩ ──┐
                                ├──→ ADC1_IN11
                    5.1kΩ ─────┘
                    68nF (到 GND, 截止 ~482 Hz)
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 分压比 | 100/5.1 = 19.6:1 | 增益 = (100+5.1)/5.1 ≈ 20.6 |
| 滤波电容 | 68 nF | RC = 5.1k×68n ≈ 0.35 μs（实际受 PCB 寄生影响） |
| 截止频率 | ~482 Hz | 一阶 RC 低通 |
| ADC 端等效电阻 | ~4.85 kΩ | 分压 + ADC 输入电容 |

### 为什么需要两种电压源

| 电压源 | 优点 | 缺点 | 适用 |
|--------|------|------|------|
| **实测**（ADC 规则组） | 直接测量，无 PWM 噪声 | 受 PCB 布线阻抗、开关耦合影响 | 低速（反电动势小，重构误差占比大） |
| **重构**（占空比×Vbus） | 无测量噪声，精度高 | 死区、母线纹波引入误差 | 高速（端电压接近母线，ADC 动态范围不够） |

### 融合策略（motor_app.c → MotorApp_UpdateObserverVoltage）

```
选择逻辑（迟滞区间防抖）:
  if 快照超时 (>250 拍 = 10ms):
    measured_selected = 0     ← 强制重构
  elif |speed| >= 1200 rpm:
    measured_selected = 0     ← 高速用重构
  elif |speed| <= 900 rpm:
    measured_selected = 1     ← 低速用实测
  else:
    保持上次选择（900~1200 迟滞区间）

渐变:
  blend_step = Ts / 0.020 = 40μs/20ms = 0.002/拍
  if measured_selected:
    weight = min(weight + 0.002, 1.0)
  else:
    weight = max(weight - 0.002, 0.0)

融合（在 observer.c → Observer_RebuildVoltage）:
  u_α = u_calc_α + weight × (u_meas_α - u_calc_α)
  u_β = u_calc_β + weight × (u_meas_β - u_calc_β)
```

### 重构电压公式推导

```
三相相电压（对地）:
  u_a = (Da - 0.5) × Vbus
  u_b = (Db - 0.5) × Vbus
  u_c = (Dc - 0.5) × Vbus

Clarke:
  u_α = (2u_a - u_b - u_c) / 3
      = [2(Da-0.5)Vbus - (Db-0.5)Vbus - (Dc-0.5)Vbus] / 3
      = Vbus × (2Da - Db - Dc - 1 + 0.5 + 0.5) / 3
      = Vbus × (2Da - Db - Dc) / 3     ← 0.5 公共项完全抵消

  u_β = (u_b - u_c) / √3
      = Vbus × (Db - Dc) / √3
```

比先算三相再 Clarke 少 3 次减法和 1 次乘法。

### 超时保护

```
stale_count 每拍递增（无新快照时）
stale_count > 250 (10ms) → 强制 measured_selected = 0
```

防止主循环卡死（如串口阻塞）时，控制中断使用 10 ms 前的陈旧端电压。

## 板级参数初始化 (FOC_Data_Init)

### 调用时序（不可乱）

```
main()
  │
  ├─ FOC_Data_Init()              ← 必须最先
  │    写入 foc.timer:
  │      pwm_arr = 3399
  │      adc_trigger = 3398
  │      dead_time = 90
  │      clock_freq = 170000000
  │      Ts = (3399+1)×2/170000000 = 0.00004s
  │    写入 foc.current:
  │      gain_a/b/c = 0.0067138671875
  │    写入 foc.calibration:
  │      calibrated = 0, offset = 0
  │    Observer_Init():
  │      复制电机参数 (Rs=0.5, Ls=100μH, λ=2.84mWb, pp=7)
  │      复制观测器配置 (gain=5e7, Ts=40μs, PLL参数)
  │      初始磁链: x_α=λ, x_β=0
  │
  ├─ MX_TIM1_Init()               ← 读取 foc.timer
  │    用户代码段:
  │      htim1.Init.Period = foc.timer.pwm_arr
  │      htim1.Init.RepetitionCounter = 0
  │      死区 = foc.timer.dead_time
  │      CCR4 = foc.timer.adc_trigger
  │
  ├─ MX_ADC1/2_Init()
  ├─ MX_OPAMP1/2/3_Init()
  ├─ MX_CORDIC_Init()
  ├─ MX_FDCAN1_Init()
  ├─ MX_USART1_UART_Init()
  │
  └─ MotorApp_Init()
       └─ FOC_Control_Init(&motor_control, foc.timer.Ts)
```

### 参数表

| 参数 | 值 | 来源 | 说明 |
|------|-----|------|------|
| `pwm_arr` | 3399 | 硬件设计 | TIM1 ARR，中心对齐 |
| `Ts` | 40 μs | (ARR+1)×2/170MHz | 完整 PWM 周期 |
| `adc_trigger` | 3398 | 硬件设计 | CH4 触发位置（载波顶点） |
| `dead_time` | 90 | 功率板设计 | DTG 编码 ≈ 529 ns |
| `clock_freq` | 170 MHz | 系统时钟 | TIM1 计数时钟 |
| `gain` | 0.0067138671875 | 硬件电路 | 3.3/4096/(5mΩ×24) |
| `Rs` | 0.5 Ω | 电机铭牌/测量 | 相电阻 |
| `Ls` | 100 μH | 电机铭牌/测量 | 相电感 |
| `flux_linkage` | 0.00284 Wb | 电机铭牌/测量 | 永磁磁链 |
| `pole_pairs` | 7 | 电机铭牌 | 极对数 |
| `observer.gain` | 5×10⁷ | 调试经验 | 径向校正增益 |
| `pll_kp` | 400 | 控制设计 | ωn=200 rad/s, ζ=1 |
| `pll_ki` | 40000 | 控制设计 | 同上 |
| `pll_omega_limit` | ±50000 rad/s | 安全裕量 | ≈ 11366 rpm 电转速 |

## seqlock 并发机制

### 问题

主循环写 `board_adc_measurements`（多字段），控制中断读。
不能加锁（中断中不能阻塞），需要无锁一致性保证。

### 方案：seqlock

```
主循环（写端）:
  board_adc_sequence++        ← 变奇数 = 正在写
  __DMB()                    ← 内存屏障
  board_adc_measurements = next  ← 写入数据
  __DMB()                    ← 内存屏障
  board_adc_sequence++        ← 变偶数 = 写完
  board_adc_valid = 1

控制中断（读端）:
  seq_before = board_adc_sequence
  if (seq_before & 1) → return 0    ← 奇数 = 正在写，放弃
  __DMB()
  local = board_adc_measurements
  __DMB()
  seq_after = board_adc_sequence
  if (seq_before != seq_after) → return 0  ← 写入期间被读，放弃
  if (!isfinite(...)) → return 0           ← 数据无效
  *snapshot = local
  return 1
```

### 正确性分析

| 场景 | seq_before | seq_after | 结果 |
|------|-----------|-----------|------|
| 无并发 | 偶数 N | 偶数 N | ✅ 接受 |
| 读期间主循环开始写 | 偶数 N | 奇数 N+1 | ❌ 拒绝（N≠N+1） |
| 读期间主循环写完 | 偶数 N | 偶数 N+2 | ❌ 拒绝（N≠N+2） |
| 读时正在写 | 奇数 | — | ❌ 拒绝（奇数检查） |
| 主循环卡死在写中 | 奇数 | — | ❌ 拒绝（安全） |

### 为什么不用互斥锁

- 控制中断 25 kHz，不能阻塞
- 主循环写操作 < 1 μs，seqlock 读端单次尝试 < 100 ns
- 失败时沿用上一拍缓存值（40 μs 前的数据），对控制无影响

### 内存屏障

`__DMB()` 确保：
1. 写端：数据写入在 `sequence++` 之前完成
2. 读端：数据读取在 `sequence` 第二次读取之前完成
3. ARM Cortex-M4 上 `__DMB()` 对应 DMB 指令，保证 store-load 顺序

## 电压采样链路 (board_adc.c)

### 硬件

| 引脚 | ADC | 通道 | 被测 | 分压 |
|------|-----|------|------|------|
| PA0 | ADC1 IN1 | 规则 R0 | 母线电压 | 100k/5.1k |
| PB12 | ADC1 IN11 | 规则 R1 | U 相端电压 | 100k/5.1k |
| PA4 | ADC2 IN17 | 规则 R0 | V 相端电压 | 100k/5.1k |
| PB11 | ADC1 IN14 | 规则 R2 | W 相端电压 | 100k/5.1k |

### 换算

```
引脚电压 = raw × (3.3/4096)
端电压  = 引脚电压 × (105.1/5.1) = 引脚电压 × 20.608

组合系数 = 3.3/4096 × 20.608 = 0.016575 V/计数

例: raw = 2000 → 引脚 = 1.613 V → 端电压 = 33.2 V
```

### 数据发布

```
BoardAdc_Update() 成功:
  next.vbus_raw = adc1_values[0]
  next.phase_u_raw = adc1_values[1]
  next.phase_w_raw = adc1_values[2]
  next.phase_v_raw = adc2_value
  next.vbus_voltage = vbus_raw × 0.016575
  next.phase_u_voltage = ...
  seqlock 发布

BoardAdc_Update() 失败:
  不发布，共享测量值保持上一轮完整结果
```
