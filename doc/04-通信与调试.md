## 串口控制台 (debug_console.c)

### 架构

```
┌─────────────────────────────────────────────────────────────────┐
│ 硬件层                                                          │
│  USART1 (2 Mbps) ← DMA1_Ch1 (RX) + DMA1_Ch2 (TX)              │
│  DMA RX: 空闲/完成事件 → HAL_UARTEx_RxEventCallback (中断)      │
│  DMA TX: 传输完成 → HAL_DMA_IRQHandler (中断)                   │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 中断上下文
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 搬运层 (DebugConsole_OnRxEvent)                                  │
│  遍历 DMA 缓冲区的 size 个字节                                   │
│  逐字节 push 到环形队列 (DC_RingPushFromISR)                     │
│  然后重启 DMA 接收 (DC_StartReceive)                             │
└──────────────────────────┬──────────────────────────────────────┘
                           │ 256 字节环形队列
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 解析层 (DebugConsole_Process, 主循环)                            │
│  pop 字节 → 组装文本行 (CR/LF/CRLF 结束, 退格支持)              │
│  完整行 → DC_ParseLine → 切分参数 → 匹配命令                    │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│ 执行层                                                          │
│  内置: help / list / get / set                                  │
│  用户: status (MotorApp_DebugStatus)                            │
│  变量: 32 个注册变量 (F32/I32/U32/Bool)                        │
└─────────────────────────────────────────────────────────────────┘
```

### 环形队列

| 参数 | 值 | 说明 |
|------|-----|------|
| 容量 | 256 字节 | 必须 2 的幂（位运算取模） |
| 写指针 | `dc_ring_head` | ISR 推进 |
| 读指针 | `dc_ring_tail` | 主循环推进 |
| 满条件 | `(head+1) & 255 == tail` | 保留一格区分满/空 |
| 空条件 | `head == tail` | |
| 溢出处理 | 丢弃当前字节，`dc_overflow_count++` | 不阻塞 ISR |

### 行组装规则

| 输入字节 | 行为 |
|----------|------|
| `\n` (0x0A) 或 `\r` (0x0D) | 行结束，若行非空则解析 |
| CRLF | CR 触发解析，LF 产生空行（不重复执行） |
| 0x08 (Backspace) 或 0x7F (DEL) | 删除行尾字符 |
| 可打印字符 (isprint) 或 `\t` | 追加到行缓冲 |
| 其他 | 忽略 |
| 行超过 127 字符 | 标记溢出，丢弃后续字符直到行结束 |

### 命令解析 (DC_Tokenize + DC_ParseLine)

```
输入: "set speed 1500 # 目标转速\n"

DC_Tokenize:
  跳过前导空格
  遇到 '#' → 停止（注释）
  按空白切分:
    argv[0] = "set"
    argv[1] = "speed"
    argv[2] = "1500"
  argc = 3

DC_ParseLine:
  匹配内置: "set" → DC_CommandSet(3, argv)
    variable = FindVariable("speed")  ← 不区分大小写
    检查 read_only
    解析 argv[2] 为 float
    范围检查: -15000 ≤ 1500 ≤ 15000 ✅
    *(volatile float*)address = 1500.0
    输出 "OK speed=1500\n"
```

### status 命令输出

```
STATUS run=1 state=1 cal=1 idle_reset=1 adc_irq=12345 ARR=3399 CCR4=3398 MOE=1
DRIVE Vbus=24.012 cmd=1500.0 ref=1500.0 rpm=1498.7 speed_en=1
CURRENT Iq_ref=2.341 Id=0.012 Iq=2.318 Ud=0.050 Uq=1.234 Ulim=13.578
PWM CCR=1700,1200,2200 CCER=0x0000006F CR1=0x00000015
OBSERVER phase=1.234 flux=0.002840 weight=0.000 stale=0
```

| 字段 | 含义 |
|------|------|
| `run` | 运行请求 (0/1) |
| `state` | 电机状态 (0=IDLE, 1=CLOSED_LOOP) |
| `cal` | 校准完成 (0/1) |
| `idle_reset` | IDLE 复位已执行 (0/1) |
| `adc_irq` | ADC 注入中断累计次数 |
| `ARR` / `CCR4` | TIM1 自动重装值 / 触发比较值 |
| `MOE` | 主输出使能位 |
| `Vbus` | 母线电压 (V) |
| `cmd` / `ref` | 速度命令 / 斜坡后参考 (rpm) |
| `rpm` | 观测器估计转速 (rpm) |
| `Iq_ref` / `Id` / `Iq` | 电流参考/反馈 (A) |
| `Ud` / `Uq` | 电压输出 (V) |
| `Ulim` | 电压矢量上限 (V) |
| `CCR` | 三相比较值 |
| `phase` / `flux` | 观测器角度 (rad) / 磁链幅值 (Wb) |
| `weight` / `stale` | 电压融合权重 / 超时计数 |

### 文本发送保护

```
主循环文本发送 (MotorApp_DebugConsoleTx):
  motor_console_tx_active = 1
  __DMB()
  等待 USART1 TC (最多 100ms)
  HAL_UART_Transmit(data, len, 100ms)
  motor_console_tx_active = 0

控制中断波形发送 (MotorApp_SendJustFloat):
  if motor_console_tx_active → 跳过本拍
  检查 USART1 TC
  写 just_float_frame
  启动 DMA TX
```

- 两者互斥，不会同时改写 USART1
- 文本发送等待 DMA 帧发完（避免波形帧和文本帧交错）
- 波形帧 28 字节 @ 2 Mbps ≈ 112 μs，文本帧 ≤ 192 字节 ≈ 768 μs

## CAN 协议 (motor_protocol.c)

### 帧 ID 规划

| ID | 方向 | 格式 | DLC | 用途 | 频率 |
|----|------|------|-----|------|------|
| `0x000` | 上位机→APP | Classic | 8 | Boot 控制 | 按需 |
| `0x100` | 上位机→APP | FD | 24 | 多节点控制 | 按需 |
| `0x180+n` | APP→上位机 | Classic | 8 | Boot 应答 | 按需 |
| `0x200+n` | APP→上位机 | FD | 12 | 周期反馈 | 每 10ms |
| `0x280+n` | APP→上位机 | Classic | 8 | 心跳 | 每 1s |
| `0x300+n` | APP→上位机 | FD | 64 | 调试反馈 | 每 2ms |
| `0x380+n` | APP→上位机 | Classic | 8 | HELLO | 上电一次 |

`n` = 节点号 (1~8)。

### 控制帧 (ID 0x100, 24 字节 FD)

```
Byte 0:  协议版本 (固定 = 1)
Byte 1:  命令码
  0x10 = SPEED_VECTOR   速度向量
  0x11 = RUN_VECTOR     启停向量
  0x20 = DEBUG_SELECT   调试节点选择
  0x30 = STATUS_ONCE    立即发一次反馈
Byte 2:  目标节点位图 (bit0=节点1, bit1=节点2, ..., bit7=节点8)
Byte 3:  RUN_VECTOR 时的运行位图 (bit n=1 → 节点 n+1 启动)
Byte 4-7: 保留 (=0)
Byte 8-23: 8 个 int16 速度值 (小端), 每节点 2 字节
  Byte 8-9:   节点1 速度 (rpm, int16, 范围 -10000~10000)
  Byte 10-11: 节点2 速度
  ...
  Byte 22-23: 节点8 速度
```

### 周期反馈帧 (ID 0x200+n, 12 字节 FD)

```
Byte 0-1:  转速 (rpm, int16, 比例×1)
Byte 2-3:  Iq (A, int16, 比例×100)
Byte 4-5:  Vbus (V, uint16, 比例×100)
Byte 6-7:  保留 (温度, 当前 = 0)
Byte 8:    状态码 (0=IDLE, 2=CLOSED_LOOP)
Byte 9:    标志位
  bit0: 校准完成
  bit1: 速度环使能
  bit2: SVPWM 限幅
  bit3-7: 保留
Byte 10:   反馈序号 (uint8, 每帧+1, 溢出回绕)
Byte 11:   保留 (=0)
```

### 调试反馈帧 (ID 0x300+n, 64 字节 FD)

```
Byte 0-1:   转速 (rpm, int16, ×1)
Byte 2-3:   电角速度 (rad/s, int16, ×1)
Byte 4-5:   U 相电流 (A, int16, ×100)
Byte 6-7:   V 相电流 (A, int16, ×100)
Byte 8-9:   W 相电流 (A, int16, ×100)
Byte 10-11: Id (A, int16, ×100)
Byte 12-13: Iq (A, int16, ×100)
Byte 14-15: Ud (V, int16, ×100)
Byte 16-17: Uq (V, int16, ×100)
Byte 18-19: Vbus (V, uint16, ×100)
Byte 20-21: 保留 (=0)
Byte 22-23: 电角度 (deg, int16, ×100)
Byte 24:    状态码
Byte 25:    校准标志
Byte 26:    速度环使能
Byte 27:    SVPWM 限幅
Byte 28:    反馈序号
Byte 29-63: 保留 (=0)
```

### 心跳帧 (ID 0x280+n, 8 字节 Classic)

```
Byte 0: 节点号 (1~8)
Byte 1: 状态码 (0/2)
Byte 2: 校准完成 (0/1)
Byte 3: 调试使能 (0/1)
Byte 4: 保留 (=0)
Byte 5: SVPWM 限幅 (0/1)
Byte 6: 反馈序号 (uint8)
Byte 7: CRC8 (Byte0~6, 多项式 0x07, 初值 0x00)
```

### HELLO 帧 (ID 0x380+n, 8 字节 Classic)

```
Byte 0-4: 'H','E','L','L','O'
Byte 5:   节点号
Byte 6:   保留 (=1)
Byte 7:   CRC8 (Byte0~6)
```

### Boot 控制帧 (ID 0x000, 8 字节 Classic)

```
Byte 0: 目标节点号 (1~8) 或 0xFF (广播)
Byte 1: 命令码 (0x04 = ENTER_BOOT)
Byte 2-6: 保留 (=0)
Byte 7: CRC8 (Byte0~6)
```

### 旧版兼容帧 (ID 0x100, 8 字节 Classic)

```
Byte 0: 目标节点号 或 0xFF
Byte 1: 命令码
  0x01 = 运行控制 (Byte3 = 0 停 / 1 启)
  0x02 = 速度设置 (Byte3~6 = IEEE754 float rpm)
Byte 2: 保留
Byte 3-6: 数据
Byte 7: CRC8 (Byte0~6)
```

### 调度状态机

```
MotorProtocol_Process() 每主循环迭代:
  │
  ├─ PollRx(): FIFO0 → 环形队列 (8 帧)
  │    while (FIFO 非空):
  │      读帧 → 写入 rx_ring[head]
  │      head = (head+1) % 8
  │      if head == tail → 队列满，丢弃
  │
  ├─ 逐帧解析:
  │    while (tail != head):
  │      item = rx_ring[tail]
  │      tail = (tail+1) % 8
  │      HandleRx(item):
  │        ID=0x000, Classic, 8B → HandleBoot
  │        ID=0x100, FD, 24B    → HandleVector
  │        ID=0x100, Classic, 8B → HandleLegacy
  │        其他 → 忽略
  │
  ├─ RunScheduler(now):
  │    elapsed = now - last_tick (上限 20ms)
  │    for each ms in elapsed:
  │      last_tick++
  │      slot = timer_slot++  (mod 10)
  │
  │      if !debug_suppressed:
  │        if slot == (node_id - 1):
  │          SendNormalFeedback()
  │      else:  // 调试独占
  │        if debug_enabled:
  │          if ++debug_divider >= 2:
  │            debug_divider = 0
  │            SendDebugFeedback()
  │
  └─ 心跳:
       if now >= heartbeat_next_tick:
         heartbeat_next_tick = now + 1000
         SendHeartbeat()
```

### 时隙分配

| 时隙 (0-9) | 节点 |
|-----------|------|
| 0 | 节点 1 |
| 1 | 节点 2 |
| 2 | 节点 3 |
| 3 | 节点 4 |
| 4 | 节点 5 |
| 5 | 节点 6 |
| 6 | 节点 7 |
| 7 | 节点 8 |
| 8-9 | 空闲 |

- 每 10 ms 一轮，每节点每 10 ms 发一次反馈
- 调试独占时：普通反馈停止，被选节点每 2 ms 发调试帧

### CRC-8 实现

```
多项式: 0x07 (x³+x²+1)
初值:   0x00
输入反转: 否
输出反转: 否
异或输出: 0x00

算法 (逐位):
  crc = 0
  for each byte:
    crc ^= byte
    for 8 bits:
      crc = (crc & 0x80) ? (crc<<1) ^ 0x07 : (crc<<1)
```

## Boot 控制 (app_boot_control.c)

### 流程

```
上位机发送:
  ID=0x000, Classic, 8B
  [node, 0x04, 0,0,0,0,0, crc]

APP 主循环 AppBootControl_Process():
  while (FIFO0 非空):
    读帧
    检查:
      ID == 0x000
      标准帧
      数据帧
      经典 CAN
      DLC == 8
    CRC8 校验
    节点号匹配 (本节点或 0xFF 广播)
    命令 == 0x04 (ENTER_BOOT)
    → App_RequestBootloader():
        HAL_PWR_EnableBkUpAccess()
        TAMP->BKP0R = 0x544F4F42  ("BOOT")
        __DSB()
        NVIC_SystemReset()
        // 不返回

Bootloader 上电:
  检查 BKP0R == 0x544F4F42
  → 进入升级/维护流程
  → 清除 BKP0R
```

### 节点号读取

```
Flash 0x0801F800 头部:
  Word 0: magic  (0x31474643 = "CFG1")
  Word 1: version (1)
  Word 2: length  (84)
  Word 3: node_id (1~8)

APP 只读头部，不解析完整 Boot_Config_t
校验: magic + version + length + 1≤node≤8
无效 → 回退到 APP_BOOT_NODE_ID (默认 1)
```

### 构建差异

| 构建 | `APP_WITH_BOOTLOADER` | `AppBootControl_Init` | `AppBootControl_Process` |
|------|----------------------|----------------------|--------------------------|
| standalone (Debug/Release) | 0 | 空函数，返回 HAL_OK | 空函数 |
| boot (Boot-Release) | 1 | 配置 FDCAN 过滤器 | 完整轮询+处理 |
