# 术语与缩写表（补充资料）

> 本文是**查词表**：把项目里出现的缩写、领域术语和本工程自造名词集中解释一遍，方便新接手的人读代码和文档时不必反复上下文推断。
> 每条尽量给"在哪个文件里能看到它"，但不重复符号级签名（见[底层参考](05-底层参考.md)）。
> 本文不含调参数值（见[参数与调参速查](10-参数与调参速查.md)）。

## 1. 电机与驱动基础

| 缩写 / 术语 | 全称与中文 | 含义与本项目用法 |
|---|---|---|
| PMSM | Permanent Magnet Synchronous Motor，永磁同步电机 | 本工程的被控对象。反电势为正弦，需要连续角度控制，因此用 FOC 而不是六步换向 |
| BLDC | Brushless DC motor，无刷直流电机 | 反电势接近梯形，常用六步换向。本文档提到它只用于对比 |
| FOC | Field-Oriented Control，磁场定向控制 | 把定子电流投影到随转子旋转的 dq 坐标系，分别控制励磁与转矩分量 |
| 无感 / sensorless | — | 不使用位置传感器（霍尔/编码器），角度由观测器从电压电流估算 |
| 观测器 / observer | — | 由电气量反推转子角度与转速的算法。本项目用的是**非线性磁链观测器**（`Core/Src/observer.c`），**不是** SMO |
| SMO | Sliding Mode Observer，滑模观测器 | 另一种常见的无感算法；本项目未使用 |
| BEMF / 反电势 | Back-Electromotive Force | 转子旋转在定子绕组中感应的电压；无感算法赖以工作的物理量 |
| 磁链 | flux linkage，ψ | 绕组匝链的总磁通，单位 Wb。永磁磁链幅值记作 `flux_linkage` |
| 极对数 | pole pairs | 电角度是机械角度的极对数倍。本项目 `pole_pairs = 7` |
| 电角度 / 机械角度 | electrical / mechanical angle | 电角度 = 机械角度 × 极对数。控制算法里的角一律是电角度 |
| 电角速度 / 机械转速 | — | 代码里 `pll_omega_e` 是 rad/s 电角速度，`speed_rpm` 是 rpm 机械转速 |
| 负载角 | load angle | 控制电压矢量与转子磁链之间的夹角。I/F 拖动时固有存在，重载时变大 |
| 转矩电流 / 励磁电流 | — | dq 坐标下分别是 Iq（产转矩）与 Id（不产转矩）。表贴式电机通常令 `Id = 0` |
| MTPA | Maximum Torque Per Ampere，最大转矩电流比 | 本项目用近似：表贴式电机 `Ld ≈ Lq`，直接取 `Id = 0` |
| 死区 | dead time | 互补 PWM 上下管之间的强制关断间隔，防止直通。本项目 `dead_time = 90`（170 MHz 下约 529 ns） |
| 分流电阻 | shunt resistor | 串在相线/母线里的采样电阻。本项目 5 mΩ，配合约 24 倍增益 |
| 母线电压 | DC bus voltage / Vbus | 功率级直流供电电压。`voltage_limit = Vbus/√3` 的上限来源 |

## 2. 坐标变换与调制

| 缩写 / 术语 | 全称与中文 | 含义与本项目用法 |
|---|---|---|
| Clarke | Clarke transform，克拉克变换 | 三相 abc → 静止两相 αβ |
| InvClarke / 逆 Clarke | Inverse Clarke | αβ → abc |
| Park | Park transform，帕克变换 | 静止 αβ → 随转子旋转的 dq，需要控制角 |
| InvPark / 逆 Park | Inverse Park | dq → αβ，把 PI 输出的 Ud/Uq 变回静止系 |
| dq | d 轴 / q 轴 | 旋转坐标系：d 沿转子磁链方向，q 超前 90° |
| αβ | alpha / beta 轴 | 静止两相坐标系，α 对齐 A 相 |
| SVPWM | Space Vector PWM，空间矢量脉宽调制 | 用三个桥臂合成任意方向电压矢量；本项目用**共模注入法**实现等价的线性调制 |
| SPWM | Sinusoidal PWM | 逐相比较正弦的调制方式；本文档提到它只用于对比 |
| 调制比 / 电压利用率 | modulation index | 线性区最大相电压矢量幅值为 `Vbus/√3`。本项目取用满线性区 |
| 共模注入 | common-mode injection | 三相同时叠加同一个零序量，不改变线电压但提高电压利用率 |
| 占空比 | duty cycle | 本项目 0~1，`duty = 0.5 + u/Vbus` 形式由 SVPWM 输出 |
| 过调制 | overmodulation | 超过线性区，进入六步。本项目不使用 |
| 中心对齐 PWM | center-aligned PWM | 计数器上下对称计数，在中心点采样电流避开关断瞬间的振铃 |

## 3. 控制结构与环路

| 缩写 / 术语 | 全称与中文 | 含义与本项目用法 |
|---|---|---|
| PI | 比例-积分控制器 | 本项目所有环路都用 PI（没有 D）。实现见 `Core/Src/controller.c` |
| 电流环 | current loop | Id/Iq 各一个 PI，25 kHz 每拍都跑 |
| 速度环 | speed loop | 外环，按分频（默认 1 kHz）运行，输出 Iq 参考 |
| 串级 | cascade | 速度环输出作为电流环给定 |
| 分频 / divider | — | 速度环相对电流环的执行比，`speed_loop_divider = 25` |
| 抗饱和 / anti-windup | — | 输出越界且误差同向时撤回本拍积分。本项目是**条件积分**式 |
| 积分限幅 | integral clamp | 抗饱和的第三道保险，`integral_min/max` |
| 无扰切换 | bumpless transfer | 模式切换时用 `PI_Controller_PreloadOutput()` 反算积分，避免输出阶跃 |
| 饱和方向 | saturation | `PI_Saturation_t`：−1 下饱和、0 未饱和、+1 上饱和 |
| 斜坡 / slew | slew rate | 把阶跃参考变成有限变化率。速度参考单位 rpm/s，Iq 单位 A/s |
| 参考 / 反馈 | reference / feedback | 控制器的一对输入。PLL 场景没有传统参考，只用误差 |
| 圆形限幅 | circular voltage limit | dq 电压矢量幅值不超过 `Vbus/√3`；先给 d 轴，再用 `√(limit²−Ud²)` 卡 q 轴 |
| 参考仲裁 | reference arbitration | 应用层每拍通过 `FOC_Control_SubmitReference()` 提交唯一控制目标 |
| 控制角 | `theta_ctrl` | 本拍 Park/逆 Park 使用的电角度，来源由状态机决定 |
| 无扰预加载 | preload | 见"无扰切换" |

## 4. 启动与接管（本项目自造名词集中区）

| 术语 | 含义 |
|---|---|
| IDLE | 空闲：功率桥关闭、电流为零。零偏校准也在此状态完成 |
| ALIGN / 定位 | 固定电角度注入 Id（`1.0 A`，`Iq = 0`）把转子拽到已知位置，给观测器初始基准 |
| I/F / 开环拖动 | 用虚拟电角度加受限电角加速度爬升，只给 Iq（`1.5 A`）。"I/f"指按电流-频率开环驱动 |
| 虚拟角 / `virtual_angle` | I/F 阶段自己积分出来的电角度，不代表真实转子位置 |
| 强制开环 / forced open loop | 目标绝对值 ≤ 800 rpm 时保持虚拟角，观测器不参与控制角 |
| ObserverReady / 可信性判据 | 一组后台条件（最低转速、整圈净覆盖、相对漂移、电流跟踪等）持续成立，才允许接管 |
| 接管 / handover | 控制角从虚拟角平滑切换到观测器角的过程，用**渐消偏置**过渡 |
| 渐消偏置 | 接管瞬间的控制角偏差，按三次 smoothstep 在 20~150 ms 内衰减到 0 |
| 坐标搬运 | 切换坐标系时把 Id/Iq 的 PI 积分按旋转矩阵转过去（`FOC_Control_RotateCurrentIntegrals()`），**只搬"额外多出的那次旋转"**，不搬转子正常旋转 |
| Ready 位图 / `rdy_fail` | `MOTOR_APP_READY_FAIL_*` 位掩码，任一位置起表示对应判据失败 |
| 启动失败码 / `fail` | `MOTOR_APP_FAIL_*` 枚举，见 [故障排查手册](11-故障排查手册.md) |
| 穿零 | 转速参考穿越 0 rpm。本项目在 ±800 rpm 强制角下完成，避免零点跳角 |
| 闭环制动 | CLOSED_LOOP 下直接用观测器角加反向电流产生制动转矩 |
| 健康门限 | `MOTOR_APP_CLOSED_LOOP_HEALTH_*`，当前编译期关闭 |
| I/F 电流削减 | `if_trim`：同步后的稳定支路缓慢下调拖动电流，默认关 |

## 5. 采样与外设

| 缩写 / 术语 | 全称与中文 | 含义与本项目用法 |
|---|---|---|
| ADC | Analog-to-Digital Converter | 模数转换器。本项目用 ADC1/ADC2 |
| 注入组 / injected group | — | 由 TIM1 CH4 硬件触发、与 PWM 严格同步的通道组，采电流 + 三相端电压 |
| 规则组 / regular group | — | 主循环软件触发（间断模式）的慢速通道：母线电压、内部温度 |
| JEOS | Injected End Of Sequence | 注入序列结束标志，产生 `ADC1_2_IRQHandler` |
| JSQR | Injected Sequence Register | 注入序列配置寄存器，`JL` 是序列长度−1，`JSQx` 是第 x 个 Rank 的通道号 |
| Rank | 序列位置 | 注入/规则序列里的第几个转换 |
| 零偏校准 | offset calibration | 上电前 1000 次注入中断累加电流零点，之后才允许闭环 |
| 电流重构 | current reconstruction | 占空比接近 100% 时某相下管导通窗口不足，用 KCL 由另两相推算 |
| OPAMP / PGA | 运算放大器 / 可编程增益 | STM32G4 内置三个独立运放做电流信号调理。本项目把它们配成 **standalone 模式且 `InternalOutput = DISABLE`**，即**不使用内部 PGA 增益档位**，×24 增益与 1.65 V 偏置都由外部电阻网络决定（`Core/Src/opamp.c`） |
| CORDIC | Coordinate Rotation Digital Computer | 硬件三角函数加速器，用于正余弦与 atan2 |
| DWT | Data Watchpoint and Trace | Cortex-M 的周期计数器，本项目用作微秒级计时/延时（`bsp_dwt.c`） |
| TIM1 | — | 产生三相中心对齐互补 PWM 与 ADC 触发 |
| TIM6 | — | 1 ms 通信节拍（CAN 调度） |
| HAL | Hardware Abstraction Layer | ST 的外设抽象层 |
| MSP | MCU Support Package | HAL 的板级初始化回调（时钟、引脚、DMA、NVIC 的实际配置在这里） |
| IRQ / ISR | 中断请求 / 中断服务程序 | 本项目实时控制在 ADC1 JEOS 中断里 |
| VTOR | Vector Table Offset Register | 向量表偏移；Boot 布局下指向 `APP_FLASH_START` |
| DMA | Direct Memory Access | 串口收发搬运，不占 CPU |
| seqlock | 顺序锁 | 一种无锁快照：写者递增序号，读者前后各读一次序号并比对。**本项目并未实现**——`board_adc.c` 只有 `BoardAdc_Update()`/`BoardAdc_GetMeasurements()`，规则组测量由主循环独占读写；需要整组一致的诊断快照用的是 `__disable_irq()` 短临界区。源码注释里仍残留这个词 |
| 临界区 | critical section | 用 `__disable_irq()` / `__PRIMASK` 短暂关中断保护成组数据；本项目用于诊断快照的拷贝与发布 |
| 内存屏障 | memory barrier | `__DMB()` 约束编译与执行顺序，用于 DMA 使能前、跨域发布标志等场合 |

## 6. 通信与上位机

| 缩写 / 术语 | 全称与中文 | 含义与本项目用法 |
|---|---|---|
| FDCAN | Flexible Data-Rate CAN | STM32G4 的 CAN FD 外设。本项目仲裁段与数据段均 1 Mbit/s |
| CAN FD | CAN with Flexible Data rate | 支持 >8 字节载荷的 CAN 扩展 |
| Classic CAN | 经典 CAN | 载荷上限 8 字节。本项目心跳/HELLO/Boot 帧用它 |
| BRS | Bit Rate Switch，位速率切换 | 本项目**关闭**（`MOTOR_PROTOCOL_CANFD_BRS_ENABLED = 0`） |
| DLC | Data Length Code | 数据长度码。本项目用 8 / 12 / 24 / 64 字节 |
| CRC8 | 8 位循环冗余校验 | 控制帧与 Boot 帧的完整性校验 |
| 心跳 / heartbeat | — | 周期性广播"我在线"的短帧 |
| HELLO | — | 上电握手帧 |
| 反馈帧 | feedback frame | 周期性回传运行状态与测量值 |
| 时隙 / slot | — | CAN 发送调度的时间片，`SLOT_COUNT = 10` |
| 环形队列 / ring buffer | — | 中断与主循环之间的无锁字节/帧缓冲 |
| tokenize | 分词 | 把一行命令按空格切成参数。`DC_Tokenize` |
| justfloat | VOFA+ 的浮点波形协议 | 以 `f0..f6` 七个 float 加帧尾的二进制波形输出，本项目 `wave_mode` 选择通道含义 |
| VOFA / VOFA+ | 上位机波形工具 | 通过串口接收 justfloat 帧绘图 |
| wave_mode | 波形模式 | 0~3，选择七通道的含义（控制速度/速度参考/Iq_ref/Iq/Ud/Uq/Ulim 等） |
| status | — | 串口诊断命令，打印运行状态、采样、PWM、观测器与启动诊断字段 |
| startdiag | — | 串口诊断命令，打印接管/进入闭环/故障时刻锁存的快照 |
| Bootloader | 引导程序 | 外部独立程序；APP 可通过 CAN 请求返回它 |
| 配置页 | config page | Flash 末段 `0x0801F800` 起的 2 KiB，存放节点号等配置 |

## 7. 构建、工具与工程约定

| 术语 | 含义 |
|---|---|
| CMake preset | `CMakePresets.json` 里的命名构建配置：Debug / Release / Boot-Release / Boot-Release-HSE24 |
| Ninja | 本项目使用的构建后端 |
| arm-none-eabi | GNU Arm 嵌入式工具链前缀 |
| LTO | Link Time Optimization，链接期优化，Release 应用源码 `-O3/-flto` |
| ld script | 链接脚本 `STM32G431XX_FLASH.ld`（独立版）与 `STM32G431XX_BOOT_FLASH.ld`（Boot 版） |
| standalone | 独立镜像，链接到 `0x08000000`，SWD 直接烧录 |
| Boot APP | 链接到 `0x08005000`，由外部 Bootloader 加载 |
| `APP_LAYOUT` | 构建选项，选择上述两种 Flash 布局 |
| `BOARD_HSE_HZ` | 构建选项，选择 16 MHz 或 24 MHz 晶振（24 MHz 分支仅供跨板通信验证） |
| codecheck | `tools/codecheck.py`，剥离注释后比对代码 token 流，用于证明"只改注释" |
| 主机回归 / host regression | `tests/test_runtime_response.py`，在 PC 上抽取真实工程函数并编译真 `controller.c` 做数值测试 |
| 台架实测 | 在真实电机与功率级上做的验证，不能被主机回归替代 |

## 8. 状态、故障与诊断量

| 名称 | 含义 |
|---|---|
| `FOC_MOTOR_IDLE` / `FOC_MOTOR_CLOSED_LOOP` | 底层电机状态枚举（`foc_motor_state`） |
| IDLE / ALIGN / OPEN_LOOP_IF / OBSERVER_HANDOVER / CLOSED_LOOP | 应用层启动状态机的五个状态 |
| `phase` | 诊断里表示当前所处阶段/子阶段的编码（见 [08](08-双向静止启动与平滑接管修正.md) 的 phase 细分） |
| `fail` | 整机启动失败原因码 0~8 |
| `rdy_fail` | ObserverReady 失败位图，12 位 |
| `mask` | 故障时刻锁存的末拍 Ready 失败位图 |
| `hold` | 接管保持窗口的剩余/已用拍计数（25000 拍 = 1 s） |
| `n_if` / `n_obs` | 虚拟转速 / 观测转速（rpm），诊断里成对出现 |
| `delta` | 控制角与观测角的瞬时差（rad）。**它是控制角减观测角，不是独立测得的真实负载角** |
| `dtheta` | status 里的角度差显示项；停车后会混用保持控制角与复位后的观测角 |
| `sat_d` / `sat_q` | d/q 电流 PI 的饱和方向 |
| `speed_aw` | 最近一次速度 PI 是否因下游电压饱和暂停了同向积分 |
| `brake` | 高速闭环制动标志 |
| `volt_src` / `volt_weight` | 端电压来源（0 重构 / 1 实测）与融合权重 |
| `adc_cfg` | 注入序列回读自检结果 |
