#### FOC_PWM_Start()

| 项目 | 说明 |
|------|------|
| **用途** | 启动三相互补 PWM 和 CH4 ADC 触发 |
| **参数** | 无 |
| **返回值** | 无 |
| **行为** | 先将三相 CCR 置为 50% 中点，再依次启动 CH1/2/3 主输出、互补输出、CH4 |
| **注意** | `HAL_TIM_PWM_Start` 会打开 MOE，但互补通道此时尚未使能 |

#### FOC_PWM_Stop()

| 项目 | 说明 |
|------|------|
| **用途** | 停止三相主/互补 PWM 和 CH4 |
| **参数** | 无 |
| **返回值** | 无 |

#### FOC_Get_Iabc()

| 项目 | 说明 |
|------|------|
| **用途** | 将三相 ADC 原始计数换算为电流 (A)，并在占空比超限时重构一相 |
| **参数** | `handle` → FOC 句柄指针；`adc1/2/3` → U/V/W 相 ADC 原始计数 (uint16) |
| **返回值** | 无 |
| **行为** | 1) 读 CCR1~3 找最大相作为重构候选；2) 用零偏和增益换算三相电流；3) 若最大 CCR > 95% ARR，用 KCL 重构该相 |
| **电流方向** | `i = (offset - raw) × gain`，正方向为流入电机 |

#### FOC_SVPWM_Run()

| 项目 | 说明 |
|------|------|
| **用途** | 公共模注入 SVPWM：三相电压 → 占空比 + CCR |
| **参数** | `u_abc` → 三相参考电压 (V)；`vbus` → 母线电压 (V)；`timer` → 定时器参数；`output` → 输出结构体 |
| **返回值** | `HAL_OK` 正常/限幅；`HAL_ERROR` 参数无效或母线过低 |
| **行为** | 求 max/min → 判断是否需缩放 → 注入公共模 → 计算占空比 → 转 CCR |
| **限幅** | `u_span > Vbus` 时等比缩小，`voltage_scale < 1` |

#### ADC_Regular_Read_DMA()

| 项目 | 说明 |
|------|------|
| **用途** | DMA 阻塞读取 ADC 规则组（保留接口，当前未使用） |
| **参数** | 无 |
| **返回值** | `HAL_OK` / `HAL_TIMEOUT` (10 ms) / `HAL_ERROR` |

### observer.c 函数

#### Observer_Init()

| 项目 | 说明 |
|------|------|
| **用途** | 初始化观测器：复制参数、设置初始磁链为 alpha 轴正方向、初始化 PLL PI |
| **参数** | `obs` → 观测器句柄；`motor` → 电机参数 (Rs/Ls/λ/极对数)；`config` → 观测器配置 (gain/Ts/psi范围/PLL参数) |
| **返回值** | 无 |
| **初始状态** | `x_α=λ, x_β=0, ψ_α=λ, ψ_β=0, ψ_mag=λ, phase=0, pll_phase=0` |

#### Observer_Run()

| 项目 | 说明 |
|------|------|
| **用途** | 每拍执行：电压融合 → 磁链积分 → 永磁磁链提取 → 径向校正 → atan2 角度 → PLL |
| **参数** | `obs` → 观测器句柄；`input` → 本拍输入 (占空比/实测电压/权重/母线/电流) |
| **返回值** | 无 |
| **前置条件** | `initialized=1`、`Ts>0`、`vbus>0.1V`，否则直接返回 |
| **积分方法** | 前向欧拉：`x += Ts × (u - R·i + correction)` |
| **校正** | `correction = gain × (λ² - |ψ|²) × ψ`（径向非线性，约束磁链幅值） |

#### Observer_PLL_Run()

| 项目 | 说明 |
|------|------|
| **用途** | SRF-PLL 鉴相和速度估计 |
| **参数** | `obs` → 观测器句柄 |
| **返回值** | 无 |
| **行为** | 1) 检查 ψ_mag 是否在 [psi_min, psi_max] 内；2) 有效时：归一化 → CORDIC sin/cos → 鉴相 error=ψ_q → PI → ω_e → rpm；3) 无效时：保持上一拍 ω_e 继续推算角度；4) 无论是否有效，`pll_phase += ω_e × Ts` |
| **极对数** | 当前硬编码 7 极对：`rpm = ω_e × 60/(2π×7)` |

## main.c

`main.c` 除 CubeMX 生成区外只有 4 个 USER CODE 区，全部用户逻辑如下。

### main()

| 项目 | 说明 |
|------|------|
| **用途** | 程序入口：向量表重定位 → 外设初始化 → 主循环 |
| **参数** | 无 |
| **返回值** | `int`（实际不返回；错误进 `Error_Handler` 死循环） |
| **执行顺序** | ① `SCB->VTOR = APP_FLASH_START` + `__DSB(); __ISB()`；② `MotorApp_ForcePowerStageSafe()`；③ `HAL_Init()`（闪接口 + SysTick 1 ms）；④ `SystemClock_Config()`；⑤ `FOC_Data_Init()`；⑥ `MX_GPIO/DMA/TIM1/ADC1/ADC2/OPAMP1~3/CORDIC/FDCAN1/USART1_Init()`；⑦ `MotorApp_Init()`；⑧ `MotorProtocol_Init(&hfdcan1, MotorApp_GetControl())`；⑨ `while(1) { MotorProtocol_Process(); MotorApp_Process(); }` |

## stm32g4xx_it 中断向量

全部为 CubeMX 生成框架，USER CODE 区为空；用户逻辑通过 HAL 句柄分发。

| 向量 | 分发目标 | 用途 | 频率 | 优先级 |
|------|----------|------|------|--------|
| `ADC1_2_IRQHandler` | `HAL_ADC_IRQHandler(&hadc1)` + `HAL_ADC_IRQHandler(&hadc2)` | **25 kHz 控制中断**：ADC1 JEOS 触发 `MotorApp_OnInjectedConversion`；ADC2 句柄共享向量但不开中断，仅清标志 | 25 kHz | 0（最高） |
| `TIM1_UP_TIM16_IRQHandler` | `HAL_TIM_IRQHandler(&htim1)` | TIM1 更新事件（当前无用户回调） | 25 kHz | 默认 |
| `USART1_IRQHandler` | `HAL_UART_IRQHandler(&huart1)` | USART1 错误/事件（正常 RX 走 DMA，此向量兜底） | 按需 | 默认 |
| `DMA1_Channel1_IRQHandler` | `HAL_DMA_IRQHandler(&hdma_usart1_rx)` | USART1 RX DMA 完成 → `HAL_UARTEx_RxEventCallback` | 按需 | 默认 |

| `CORDIC_IRQHandler` | `HAL_CORDIC_IRQHandler(&hcordic)` | CORDIC 中断（当前寄存器直读不用，向量保留） | — | 0 |
| `SysTick_Handler` | `HAL_IncTick()` | HAL 时基 1 ms | 1 kHz | 15（最低） |
| `NMI/HardFault/MemManage/BusFault/UsageFault` | 死循环 | 异常兜底，不返回 | — | — |

| 函数 | 输入 | 输出 / 副作用 | 返回值 |
|---|---|---|---|
| SVC_Handler() | 无 | 当前无 RTOS 服务逻辑，保留 Cortex-M 异常入口 | void |
