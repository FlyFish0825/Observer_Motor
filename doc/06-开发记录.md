# 开发记录（补充资料）

> 本文保留项目阶段记录和数值库约定，不属于三层架构阅读路径。代码结构和当前行为以第一至第三层文档及源码为准。

## 阶段记录

### 第一批：电机驱动、串口启停与 ADC 规则组

提交：653f0f9。

- motor_app：增加 run 启停请求；上电校准后保持 IDLE；停止时安全关桥；增加 status 分组诊断；文本回复与 VOFA DMA 发送互斥。
- debug_console：支持 CR、LF 和 CRLF 命令结束方式。
- adc.c、board_adc.c、Observer.ioc：ADC1 规则组改为间断模式，每次软件触发并读取一个 Rank，依次获得母线、U 相、W 相电压；V 相由 ADC2 规则组读取。
- main.c：移除启动前临时阻塞发送，保留应用初始化、主循环和 HAL 回调转发。
- motor_app.h：同步启动行为和主循环职责说明。

### 第二批：APP 端 CAN 返回 Bootloader

提交：260cfdf。

- FDCAN1 仲裁速率为 500 kbit/s，数据速率为 5 Mbit/s，并同步保存到 Observer.ioc。
- APP 接收标准 ID 0x000，以掩码 0x7FF 匹配；其他标准帧、扩展帧和远程帧不进入该接收路径。
- 主循环轮询 FIFO0，检查标准数据帧、Classic CAN、8 字节长度、目标节点、命令和 CRC8。
- 合法 ENTER_BOOT 命令写入 TAMP->BKP0R 的 BOOT 魔数并软件复位；APP 不发应答，重新进入 Bootloader 即表示请求已执行。
- APP 不启动或喂 IWDG，也不复制 Bootloader 状态机，只保留返回 Bootloader 的路径。

### 第三批：独立版与 Boot 版双 Flash 布局

提交：8ed201f。

- Debug、Release 链接到 0x08000000，输出 Observer_standalone.bin，用于 SWD 独立烧录。
- Boot-Release 链接到 0x08005000，输出 Observer_boot.bin，用于 Bootloader 升级。
- Boot 版 APP 截止到 0x0801F7FF，保留 0x0801F800~0x0801FFFF 的 2 KiB 配置页。
- APP_FLASH_START 同时控制链接地址和 SCB->VTOR；APP_WITH_BOOTLOADER 只在 Boot 构建中启用 CAN 返回逻辑。

## 数值计算约定

- 核心代码统一包含 arm_math.h，适用的运算优先使用 CMSIS-DSP 接口。
- 磁链幅值开方使用 arm_sqrt_f32；正余弦使用 STM32 CORDIC；磁链角度使用现有快速 atan2 近似。
- 标量绝对值保留 fabsf；当前编译器会将其生成 FPU VABS.F32 指令。isfinite 用于排除 NaN 和无穷值。
- 当前 arm_math.h 内部仍包含 math.h；GCC 路径中的 arm_sqrt_f32 也会使用 sqrtf。更换头文件不等于移除全部数学库依赖，也不直接代表性能提升。
