# 控制层：从采样、电压模型到闭环输出

> 本篇把数学量、代码字段和调用顺序对应起来。默认值来自本次源码，不代表硬件参数已经重新辨识，也不代表带载稳定性已经完成验证。启动与换向的完整状态分支见第08篇。

## 2. Clarke 与 Park：输入输出到底是哪一组量

### 2.1 静止坐标变换

采用工程中的幅值不变 Clarke：

```text
α = (2a − b − c)/3
β = (b − c)/√3

逆变换：
a = α
b = −α/2 + √3·β/2
c = −α/2 − √3·β/2
```

三相同加一个共模量，Clarke 输出不变。因此端电压是对地采样，仍可以先 Clarke 消去理想共模，再作为电机电压模型输入。但三路采样不同步、增益不同或滤波不同，会使共模抑制不再理想。

### 2.2 旋转坐标变换

```text
d =  α cosθc + β sinθc
q = −α sinθc + β cosθc

α = d cosθc − q sinθc
β = d sinθc + q cosθc
```

正反变换应使用同一拍同一组 sin/cos。若 Park 用虚拟角、逆 Park 却用观测角，PI 的误差与输出电压会处在不同坐标系，不能靠调整增益补救。

来源：[`FOC_Clarke()`](../Core/Inc/foc_math.h#L475)、[`FOC_Park()`](../Core/Inc/foc_math.h#L488)、[`FOC_InvPark()`](../Core/Inc/foc_math.h#L502)、[`FOC_InvClarke()`](../Core/Inc/foc_math.h#L515)。

### 2.3 为什么 I/f 的 Iq 不能直接当成转矩电流

设 δ=θ_virtual−θ_rotor，虚拟系给 id=0、iq=I。旋到真实转子系：

```text
id,r = −I sinδ
iq,r =  I cosδ
Te ≈ (3/2)·p·ψf·iq,r       （Ld=Lq、模型及坐标正确的前提）
```

用当前模型 p=7、ψf=0.00284 得 Kt=0.02982 N·m/A。I=1.5 A 且 |δ|=60° 时有效 q 分量只有0.75 A。坐标逐渐对齐而旧坐标的 Iq 数值不变，会改变投影转矩；这正是需要专门设计交接的原因。该公式不能把**估计**角差直接升级为已测得的真实负载角。

## 3. 同一拍的完整计算路径

```text
ADC电流 → FOC_Get_Iabc → Clarke
                         ↓
上一拍占空比 + 当前电流 + 端电压/母线 → Observer_Run
                         ↓
AdvanceStateMachine → ResolveControlReference
                         ↓
θc → CORDIC → Park → FOC_Control_Run
                         ↓
逆Park → 逆Clarke → FOC_SVPWM_Run
                         ↓
有限性/状态守卫 → TIM1 CCR1/2/3 → 拍末状态交接
```

`FOC_SVPWM_Run()` 只计算结果，不自行写 TIM1。相寄存器写入集中在应用中断入口，所以任何错误返回之后都能再次确认是否允许驱动。

来源：[`MotorApp_OnInjectedConversion()`](../Core/Src/motor_app.c#L1877)、[`MotorApp_RunCurrentLoop()`](../Core/Src/motor_app.c#L752)。

## 4. 电压输入：实测与重构的融合

由上一拍占空比重构：

```text
uα,calc = Vbus·(2Da − Db − Dc)/3
uβ,calc = Vbus·(Db − Dc)/√3
uobs = ucalc + w·(umeas − ucalc),  0≤w≤1
```

当前选择是带迟滞的：速度绝对值≥1200 rpm 时选择重构，≤900 rpm 时选择实测，中间保留原选择；权重每拍改变 Ts/0.020，整个0→1约20 ms。这是**限速渐变**，不是指数一阶滤波器。

最新实现中 I/f 段用**虚拟速度**决定来源，其余段用观测原始速度；权重选择位与最终权重不是同一个量。观测器本身还会限制有效权重。端电压 RC 相移、死区和管压降没有因为“融合”自动消失。

来源：[`Observer_RebuildVoltage()`](../Core/Src/observer.c#L83)、[`MotorApp_OnInjectedConversion()`](../Core/Src/motor_app.c#L1877)。板级传递函数见第03篇。

## 5. 磁链观测器：离散更新的先后顺序

### 5.1 模型与状态

在等电感、静止 αβ 模型中，总磁链 x=L·i+ψ。电压方程为 dx/dt=u−R·i。单纯积分会累积偏置，因此代码加入幅值约束校正：

```text
ψk = xk − L·ik
εk = ψf² − (ψα,k² + ψβ,k²)
ck = γ·εk·ψk
xk+1 = xk + Ts·(uk − R·ik + ck)
ψk+1 = xk+1 − L·ik
θ̂ψ = atan2(ψβ,k+1, ψα,k+1)
```

这里最后一行仍用本次输入 ik，不凭空使用尚未采到的 ik+1。幅值误差和校正项先根据更新前的状态计算，Euler 更新后才重新计算输出磁链和角度。

来源：[`Observer_Run()`](../Core/Src/observer.c#L151)。

### 5.2 校正项能做什么，不能做什么

当磁链模长偏小时 ε>0，校正倾向于向外；偏大时倾向于向内。它的瞬时方向与估计磁链同向，但整个闭环估计仍受电压误差、电流误差和时序影响，不能据此声称最终角度完全不受 gain 影响。

当前 γ=3×10⁷、λ=0.00284。在“电压模型理想且只考察平衡幅值附近小扰动”的简化条件下，径向误差衰减率约2γλ²，可算局部时间尺度约2.07 ms。**这不是观测器真实带宽，更不是整机同步时间**；不能用 1/(γλ) 直接当成通用时间常数。

### 5.3 参数偏差如何进入观测

| 偏差来源 | 如何进入方程 | 更适合查什么 |
|---|---|---|
| R 不准确/温升 | R·i 压降扣除有误 | 同一速度不同负载的角度/磁链变化 |
| L 不准确 | x−L·i 分离永磁磁链有误 | 电流变化期间的磁链跳动 |
| 电流零偏 | 同时污染 Ri 与 Li | 关桥零点、正负电流对称性 |
| 电压分压/滤波 | 积分输入幅值、相位偏差 | 端电压与重构电压的幅相差 |
| duty 时序错位 | 本次电流对应的实际电压不同 | 采样触发与 CCR 装载时序 |
| λ 配置不准确 | 径向约束目标错误 | 幅值受限正常但速度/角度仍异常 |

“ψ_mag 稳定”只是必要线索，不足以证明角度正确；径向校正本身就在推动幅值回到目标。

## 6. SRF-PLL 与三条不同用途的速度

### 6.1 PLL 的误差与积分

```text
ePLL = −(ψα/|ψ|) sinθ̂PLL + (ψβ/|ψ|) cosθ̂PLL
     = sin(θ̂ψ − θ̂PLL)
ω̂e = PI(ePLL)
θ̂PLL ← wrap(θ̂PLL + ω̂e·Ts)
```

小误差附近 e≈角差，理想线性模型中 Kp=400、Ki=40000 对应 ωn=200 rad/s、ζ=1。这两个参数是用于理解响应的近似，不足以宣称在采样噪声、磁链偏差和输出限幅下没有超调。

磁链有效性不通过时，代码保持最近的频率并继续推算 PLL 角。保持值仍有限不等于这段速度测量可信。机械换算处当前**写死1/7**，而非读取 motor.pole_pairs；以后换极对数必须一并检查此处。

来源：[`Observer_PLL_Run()`](../Core/Src/observer.c#L286)。

### 6.2 不同信号不能混用

| 信号 | 生成 | 当前主要用途 |
|---|---|---|
| speed_rpm | PLL 频率换算 | 最低速度/方向/单拍跳变检查，控制滤波器输入 |
| speed_rpm_f | 30 Hz 两级一阶低通串联 | Ready 速度匹配、CAN/默认波形/显示 |
| speed_feedback_rpm | 闭环/接管的100 Hz单极点 | 速度 PI 与运行低速边界；I/f时改用虚拟速度 |

每级采用 k=2πfcTs/(1+2πfcTs)，y←y+k(x−y)。两个相同30 Hz极点级联并不是二阶 Butterworth；“30 Hz”是每级配置，不是整个串联系统严格的−3 dB点。三条速度都来自软件估计，彼此吻合不构成独立测速证据。

来源：[`Observer_Init()`](../Core/Src/observer.c#L20)、[`Observer_PLL_Run()`](../Core/Src/observer.c#L286)、[`MotorApp_ControlSpeedFeedback()`](../Core/Src/motor_app.c#L738)。

## 7. 参考仲裁：把命令与实际采用值分开

`FOC_Control_SubmitReference()` 提交 θc、id_ref、iq_ref、速度模式；随后把覆盖值复位为 speed_slew_limit=−1、iq_slew_limit=0。应用层有阶段约束时必须在 Submit 之后再写覆盖值。

三个速度量：`speed_command_rpm` 是用户意图，`speed_ref_rpm` 是本阶段内部目标，`speed_ref_active_rpm` 是真正送给 PI 的斜坡参考。例如反转请求−8000 rpm到来时，高速闭环制动可先采用内部目标0，但用户命令仍为−8000；这不等于执行了“用户 set speed 0 停机”。

两个电流量：`iq_ref_target` 是本阶段/最近速度 PI 得出的可达目标，`iq_ref_active` 是逐拍限速后采用值。外部 `iq_ref` 在速度模式下不等于实时有效转矩请求。

来源：[`FOC_Control_SubmitReference()`](../Core/Src/controller.c#L851)、[`MotorApp_ResolveControlReference()`](../Core/Src/motor_app.c#L638)。

## 8. 位置式 PI、条件积分与无扰预加载

### 8.1 通用 PI 的代码形式

```text
P = Kp·e
Itry = clamp(Iold + Ki·e·Ts, Imin, Imax)
utry = P + Itry
若 utry 超过上限且 e>0，或低于下限且 e<0：撤回本拍积分
u = clamp(P + Iaccepted, umin, umax)
```

`integral` 已包含 Ki，单位与输出相同。电流 PI 中是 V；速度 PI 中是 A。更改 Ki 时不能把这个字段误当成裸误差积分再次乘一次 Ki。

### 8.2 预加载不是清零

```text
Iseed = desired_output − Kp·(reference − feedback)
```

预加载先考虑输出和积分范围，因此只能在可实现范围内衔接。速度模式从0→1时，代码把有效速度参考设为当前控制反馈，再把速度 PI 输出播种到已有 Iq。首拍零速度误差不代表输出必须为零，而是由已有积分接住原输出。

来源：[`PI_Controller_RunError()`](../Core/Src/controller.c#L295)、[`PI_Controller_PreloadOutput()`](../Core/Src/controller.c#L570)、[`FOC_Control_Run()`](../Core/Src/controller.c#L891)。

### 8.3 换坐标时搬运什么

接管中只搬运附加偏置变化导致的 PI 电压积分旋转：旧offset−新offset。正常转子的逐拍旋转不应再额外重复搬运。搬运不是将积分置零；变换后仍要按当拍电压额度限制。

来源：[`FOC_Control_RotateCurrentIntegrals()`](../Core/Src/controller.c#L1241)。

## 9. 速度环：斜坡、分频和两种抗饱和

速度参考在25 kHz每拍限速推进，速度 PI每25拍运行。默认升速参考率20000 rpm/s。目标要求减速、没有应用阶段覆盖、配置率处于指定区间等条件同时成立时，代码采用60000 rpm/s的减速参考率；自定义较小率仍被尊重，0表示冻结参考。

减速命令发生变化时，代码可以把仍超前的内部参考拉回反馈，并清除与旧驱动方向同号的积分贡献。它不是每拍都清积分，也不是将电流直接翻号。

第一层抗饱和在速度 PI 自身 ±10 A 输出内；第二层看 q 轴电压饱和与电流/速度误差方向，阻止继续推动无法实现电压方向的积分。后级 Iq 限速触发时还会按可达目标反馈积分，但有方向条件，避免制动时把旧方向转矩反复灌回积分。

来源：[`FOC_Control_Run()`](../Core/Src/controller.c#L891)、[`Core/Inc/controller.h`](../Core/Inc/controller.h#L1)。

## 10. 电流环与电压圆：为什么先 d 后 q

```text
Ulim = Vbus / √3 × 1.0
Ud = PI_d(id* − id),      |Ud|≤Ulim
Uq_lim = sqrt(max(0,Ulim²−Ud²))
Uq = PI_q(iq* − iq),      |Uq|≤Uq_lim
```

当前利用率是1.0，不是历史0.98。24 V母线对应约13.856 V矢量半径。d轴使用部分电压后，q轴只能使用剩余额度；当d轴用满，q轴余量可以降到零。因此“q电流请求很大却上不去”可能来自电压不足，并不总是Kp/Ki太小。

这只是调制与软件电压额度，不代表实际 MOSFET 没有死区压降、最低脉宽或采样窗口约束。来源：[`FOC_Control_Run()`](../Core/Src/controller.c#L891)。

## 11. SVPWM：计算占空比，不直接写桥

令 span=max(uabc)−min(uabc)。span>Vbus 时按 Vbus/span 等比缩小参考，随后用最大最小值的中点生成共模项，再计算 Da/Db/Dc与CCR。三相加同一共模不改变线电压。

关键检查：母线是否有效、输出是否有限、duty是否在0～1、是否发生末端缩放。如果电流环已经按电压圆限幅，但SVPWM仍经常缩放，应核对坐标归一化、母线年龄和数值边界，而不是只观察 limited 标志是否为零。

来源：[`FOC_SVPWM_Run()`](../Core/Src/foc_math.c#L324)、[`FOC_DutyToCCR()`](../Core/Inc/foc_math.h#L545)。

## 12. 三个手算例子：检验量纲与衔接

**电流PI首个积分增量。** Ki=1257、Ts=40μs、误差1A，则本拍积分增加0.05028V，比例贡献0.220V；尚未触发限幅且初始积分为0时，合计0.27028V。不能把Ki当成已经乘过Ts的离散系数。

**Iq变化率。** 运行100A/s、40μs步长，每拍最多改变0.004A；跨1ms速度周期最多0.1A。实际负载达到新转矩还受电流环和电压余量影响。

**坐标交接。** 虚拟iq=1.5A、δ=−70°且id=0，转换后 dobs≈1.410A，qobs≈0.513A。速度模式下当前方案让 dobs随blend减小，qobs随blend²减小；电流模式才保持qobs。不能继续用“整个接管转矩完全不变”描述当前速度模式。

来源：[`MotorApp_ResolveControlReference()`](../Core/Src/motor_app.c#L638)、[`MotorApp_BeginObserverHandover()`](../Core/Src/motor_app.c#L949)。数值为源码公式演算，不是实测波形。

## 13. 调参前先排除的耦合错误

先核对电流零偏与符号，再核对母线和端电压，再看控制角与PLL角的用途。只有这些基础一致时，才有意义讨论PI响应。单凭速度曲线抖动无法区分真实机械振动、观测噪声、慢速显示滤波和参考阶跃。

推荐比较链：`cmd → ref → rpm_fb → Iq_target/active → Iq → Uq/Ulim → duty`。若ref已快速变而Iq受限，关注限速/饱和；若Iq跟踪良好但观测角不稳，关注观测模型；若所有软件速度彼此接近仍不能排除共同估计偏差，需要独立机械基准。

## 源码走读与验证例题

### A. 电流环整定的一个理想模型，而非照抄增益

只考虑每轴电气对象1/(Ls+R)，PI为Kp+Ki/s，忽略采样延迟、交叉耦合和逆变器非线性。在Ki/Kp=R/L时可形成理想零极点抵消，期望电流带宽ωc对应Kp=Lωc、Ki=Rωc。这解释了参数与R/L的关系，但不能直接据此宣称当前闭环就是该带宽。

当前R=0.5Ω、L=100μH，R/L=5000s⁻¹；而Ki/Kp=1257/0.220≈5713.6s⁻¹，并不是严格抵消。仅由Kp/L得到2200rad/s是比例相关尺度，不能据此报告实测带宽350Hz。电角高速时dq耦合、调制延迟和电流采样会改变响应，电压饱和时线性模型更不适用。

验收应实际记录给定阶跃、dq电流响应、过冲、稳定误差与限幅是否参与。未显式补偿的交叉耦合/反电势也要归入电压预算，而不是把所有高速误差归因于积分不足。

### B. 角度误差如何串扰两个电流轴

同一物理电流只因坐标差δ发生旋转，就有d'=dcosδ−qsinδ、q'=dsinδ+qcosδ。若真实d=0、q=2A，坐标偏差10°会造成约0.347A的d分量。这是几何演算，不代表每一个Id偏移都是角度错误；电流增益、采样延迟和真实励磁请求也能造成偏移。

因此调试时要同时看本拍Id参考、反馈和控制角来源。接管中Id参考本来就不为零，简单用“Id绝对值应接近零”判断整个接管过程会错误。

### C. 滤波器的采样顺序

当前显示滤波先更新y1，再用更新后的y1更新第二级；这与把两个旧状态同时更新有微小离散差别。Ts改变时必须重算k。当前100Hz控制一阶滤波在40μs下k约0.02452，30Hz每级约0.00748。若错误地把1ms填进40μs调用的滤波器，等效物理截止会显著改变。
