## 观测器

### 物理模型

PMSM 在静止 αβ 坐标系中的电压方程：

```
u_α = R·i_α + dψ_α/dt
u_β = R·i_β + dψ_β/dt
```

其中定子总磁链 `ψ = L·i + ψ_f`（ψ_f 为永磁磁链，幅值恒定，方向跟随转子）。

观测器直接积分总磁链：

```
x_dot_α = u_α - R·i_α + correction_α
x_dot_β = u_β - R·i_β + correction_β
```

然后扣除电感磁链得到永磁磁链：

```
ψ_f_α = x_α - L·i_α
ψ_f_β = x_β - L·i_β
```

### 非线性径向校正

纯积分观测器存在**幅值漂移**：初始误差或噪声会使 |ψ_f| 偏离真实值 λ。
校正项沿径向（ψ 方向）施加，只修正幅值，不影响角度：

```
error = λ² - |ψ_f|²           （幅值平方误差）
correction_α = gain × error × ψ_f_α
correction_β = gain × error × ψ_f_β
```

- |ψ_f| < λ → error > 0 → 向外推
- |ψ_f| > λ → error < 0 → 向内拉
- 角度方向不变（校正与 ψ 共线）

gain = 5×10⁷ 是经验值，过大振荡，过小收敛慢。

### SRF-PLL

永磁磁链在 d 轴上，所以：

```
θ = atan2(ψ_f_β, ψ_f_α)     （真实电角度）
```

PLL 用鉴相器提取角度差，PI 输出电角速度：

```
ψ_f_α_n = ψ_f_α / |ψ_f|      （归一化）
ψ_f_β_n = ψ_f_β / |ψ_f|

error = -ψ_f_α_n · sin(θ_hat) + ψ_f_β_n · cos(θ_hat)
      = sin(θ - θ_hat)        （小角近似）

ω_e = PI(error)               （PI 输出 = 估计电角速度）
θ_hat += ω_e × Ts             （每拍积分推进）
```

### 速度换算

```
ω_m = ω_e / pole_pairs        （机械角速度，rad/s）
rpm = ω_m × 60 / (2π)        （机械转速）
    = ω_e × 60 / (2π × 7)   （当前硬编码 7 极对）
```

### 磁链有效性判断

```
psi_valid = (psi_mag > 1e-9)
          && (psi_min <= 0 || psi_mag >= psi_min)
          && (psi_max <= 0 || psi_mag <= psi_max)
```

- 有效：PLL 正常更新 ω_e
- 无效（如静止时 ψ_mag ≈ 0）：保持上一拍 ω_e，角度继续推进
- psi_min = 0.5λ, psi_max = 3λ 只控制 PLL 更新资格，**不是**磁链积分器的硬限幅

### 电压融合（Observer_RebuildVoltage）

```
u_calc_α = Vbus × (2·Da - Db - Dc) / 3
u_calc_β = Vbus × (Db - Dc) / √3

u_final_α = u_calc_α + weight × (u_meas_α - u_calc_α)
u_final_β = u_calc_β + weight × (u_meas_β - u_calc_β)
```

weight 由 motor_app.c 计算（见 [03-采样与板级.md](03-采样与板级.md#端电压融合)）。

### 关键参数设计依据

| 参数 | 值 | 设计依据 |
|------|-----|----------|
| `pll_kp` = 400 | 自然频率 ωn = √(Ki) = 200 rad/s | 对应 ~32 Hz 带宽 |
| `pll_ki` = 40000 | 阻尼比 ζ = Kp/(2√Ki) = 1 | 临界阻尼，无超调 |
| `pll_omega_limit` = ±50000 | 对应 ~11366 rpm 电转速 | 留 3 倍裕量（电机最高 ~3000 rpm 机械） |
| `gain` = 5×10⁷ | 校正时间常数 ≈ 1/(gain×λ) ≈ 0.7 ms | 快于电气时间常数 L/R = 0.2 ms |
| `Ts` = 40 μs | 必须与 PWM 周期严格一致 | 否则积分漂移 |

## 控制器 (controller.c)

### 结构

```
                    ┌──────────────────────────────────────┐
                    │            FOC_Control_Run()          │
                    │  （每电流环周期调用，40 μs）           │
                    ├──────────────────────────────────────┤
                    │                                      │
  speed_ref_rpm ──→│  速度斜坡 (20000 rpm/s)               │
  (外部命令)        │       │                              │
                    │       ▼                              │
                    │  speed_ref_active_rpm                │
                    │       │                              │
                    │       ├──→ 速度 PI (1 kHz 分频)      │
                    │  speed_rpm ──┘    │                 │
                    │  (观测器)          ▼                 │
                    │              iq_ref_active           │
                    │                   │                 │
                    │                   ├──→ Iq PI (25kHz)│
                    │  i_q (Park) ──────┘    │           │
                    │                         ▼           │
                    │                    Uq              │
                    │                                      │
                    │  id_ref ────→ Id PI (25kHz) → Ud   │
                    │  i_d (Park) ─┘                     │
                    │                                      │
                    │  电压限幅:                            │
                    │  Umax = Vbus × 0.98/√3             │
                    │  Ud 限 ±Umax                         │
                    │  Uq_limit = √(Umax² - Ud²)         │
                    │  Uq 限 ±Uq_limit                     │
                    └──────────────────────────────────────┘
```

### 速度斜坡

外部速度命令（串口/CAN）可能是阶跃，直接进入速度 PI 会造成 Iq 突变。
斜坡限制每拍最大变化：

```
max_step = slew_rpm_per_s × Ts     （20000 × 0.00004 = 0.8 rpm/拍）
delta = clamp(target - current, -max_step, +max_step)
current += delta
```

- 20000 rpm/s → 从 0 到 1500 rpm 需要 75 ms
- 斜坡在速度环使能期间始终生效
- 启动瞬间（电流→速度切换）直接同步，不经过斜坡

### 速度 PI 分频

```
speed_loop_divider = 25
每 25 拍（1 ms）执行一次速度 PI：
  iq_ref_active = speed_pi.Run(speed_ref_active_rpm, speed_rpm)
其余 24 拍保持 iq_ref_active 不变，电流 PI 仍每拍运行
```

速度环带宽 ~100 Hz（Ki=0.005, Ts_speed=1ms），分频不会降低性能。

### 无扰模式切换

**电流 → 速度**：

```
1. speed_ref_active_rpm = speed_ref_rpm（同步目标，不走斜坡）
2. PI_Controller_PreloadOutput(speed_pi, iq_ref_active, ref, fb)
   → integral = iq_ref_active - Kp × (ref - fb)
   → 第一拍输出 = iq_ref_active（与切换前完全一致）
```

**速度 → 电流**：

```
1. iq_ref = iq_ref_active（当前速度环输出变为直接 Iq 命令）
2. 电流 PI 下一拍直接用新 iq_ref
```

### 电压矢量限幅

线性 SVPWM 的最大 dq 电压矢量为 `Vbus/√3`（六边形内切圆）。
保留 2% 裕量：

```
Umax = Vbus × 0.98 / √3
```

**为什么先限 Ud 再限 Uq**：
- d 轴电压用于调节磁链（弱磁/增磁），优先级更高
- q 轴是转矩轴，用圆形剩余量：`Uq_limit = √(Umax² - Ud²)`
- 保证 `|U_dq| ≤ Umax`，SVPWM 不需要额外缩放

```
例: Vbus = 24V → Umax = 24×0.98/1.732 = 13.58 V
若 Ud = 5V → Uq_limit = √(13.58² - 5²) = √(184.4 - 25) = √159.4 = 12.6 V
```

### 条件积分抗饱和

```
if (output_unsaturated > output_max && error > 0)
   || (output_unsaturated < output_min && error < 0):
    integral = integral_old    ← 撤回本拍积分
    output_unsaturated = proportional + integral_old
```

- 输出已饱和且误差仍向饱和方向推 → 不累积积分
- 误差反向（试图退出饱和）→ 允许积分
- 避免传统"积分限幅"在退出饱和时的延迟

### PI 数学

每拍计算：

```
error = reference - feedback
proportional = Kp × error
integral += Ki × error × Ts        ← 连续时间 Ki，离散时乘 Ts
output = proportional + integral
output = clamp(output, output_min, output_max)
```

- Ki 是**连续时间**增益（单位：输出/(输入·s)），不是离散增益
- 离散化在 `RunError` 中显式乘 `sample_time`
- 电流环 Ts = 0.00004，速度环 Ts = 0.001（分频后）

## SVPWM (foc_math.c)

### 算法：公共模注入法

标准 SVPWM 需要判扇区、查表，计算量大。
公共模注入法等价但更简单：

```
输入: u_a, u_b, u_c (V), Vbus (V), ARR

1. u_max = max(u_a, u_b, u_c)
   u_min = min(u_a, u_b, u_c)
   u_span = u_max - u_min

2. 电压缩放:
   if u_span > Vbus:
     scale = Vbus / u_span
   else:
     scale = 1.0

3. 公共模:
   common_mode = -0.5 × (u_max + u_min) × scale
   （使三相关于零对称，不改变任意两相线电压）

4. 占空比:
   duty_a = 0.5 + (u_a + common_mode) / Vbus
   duty_b = 0.5 + (u_b + common_mode) / Vbus
   duty_c = 0.5 + (u_c + common_mode) / Vbus
   限幅到 [0, 1]

5. CCR:
   ccr = round(duty × (ARR + 1))
   上限 ARR（不输出 ARR+1）
```

### 为什么 duty = 0.5 + u/Vbus

三相电压对地，PWM 占空比直接决定平均电压：

```
u_avg = (duty - 0.5) × Vbus
→ duty = 0.5 + u_avg / Vbus
```

- duty = 0.5 → u = 0
- duty = 1.0 → u = +Vbus/2
- duty = 0.0 → u = -Vbus/2

### 电流采样与重构

#### 采样时序

```
TIM1 中心对齐 (ARR=3399):
  计数: 0 → 3399 → 0 → 3399 → ...
           ↑
     CH4 比较 (CCR4=3398)
     → ADC 注入触发
     → 采样在载波顶点附近
     → 低侧 MOSFET 刚关断，电流稳定
```

#### 零偏校准

```
条件: 功率桥关闭（MOE=0），无相电流
持续: 前 1000 拍（~40 ms）

每拍:
  ia_offset += ADC1->JDR1   (U相原始计数)
  ib_offset += ADC2->JDR1   (V相原始计数)
  ic_offset += ADC1->JDR2   (W相原始计数)

1000 拍后:
  ia_offset /= 1000
  ib_offset /= 1000
  ic_offset /= 1000
  calibrated = 1
```

#### 高占空比重构

```
当某相 CCR > 95% ARR 时:
  该相低侧导通时间 = (1-duty) × T_pwm
  = (1-0.95) × 40μs = 2μs
  → ADC 采样窗口太短，采样值不可靠

重构: Ia + Ib + Ic = 0
  若 A 相最大: Ia = -Ib - Ic
  若 B 相最大: Ib = -Ia - Ic
  若 C 相最大: Ic = -Ia - Ib
```

阈值在 `FOC_Data_Init()` 中计算：`threshold = 3399 × 95 / 100 = 3229`。

### CORDIC 正余弦

#### 硬件

STM32G4 内置 CORDIC 外设，6 个时钟周期完成一次正余弦计算。
配置为 COSINE 模式、Q1.31 输入、32 位输出、1 写 2 读。

#### 使用流程

```
1. 弧度 → Q1.31:
   q31 = (int32)(angle_rad / π × 2³¹)
   范围: [-π, π) → [-2³¹, +2³¹)

2. 写入 WDATA:
   CORDIC->WDATA = q31

3. 第一次读 RDATA → cos (Q1.31)
4. 第二次读 RDATA → sin (Q1.31)

5. Q1.31 → float:
   value = q31 × 2⁻³¹
```

#### 为什么不用 HAL

`HAL_CORDIC_Calculate()` 有函数调用开销和超时轮询。
FOC 控制中断中直接写寄存器，6 个时钟（~35 ns）完成，零等待。

## 控制中断完整流程

以下是 `MotorApp_OnInjectedConversion()` 的**逐步伪代码**，包含每步的寄存器操作：

```
function MotorApp_OnInjectedConversion(hadc):
    // === 入口检查 ===
    if hadc != ADC1: return
    motor_adc_irq_count++

    // === 运行请求检查 ===
    if motor_run_requested == 0:
        foc_motor_state = IDLE

    // === 状态机 ===
    if foc_motor_state != CLOSED_LOOP:
        foc_motor_state = IDLE
        MotorApp_ResetIdle():
            TIM1->BDTR &= ~MOE          ← 立即撤销输出
            if motor_idle_reset_done: return
            HAL_TIM_PWM_Stop(CH1/2/3)   ← 关主输出
            HAL_TIMEx_PWMN_Stop(CH1/2/3) ← 关互补输出
            TIM1->CCR1 = CCR2 = CCR3 = 0
            FOC_Control_Reset()
            清零 u_dq, u_alpha_beta, u_abc, svpwm
            Observer_Init()             ← 重置观测器
            voltage_source 重置
            motor_idle_reset_done = 1
    else:
        motor_idle_reset_done = 0

    // === 零偏校准（前 1000 拍）===
    if !calibrated:
        calibration_count++
        ia_offset += HAL_ADCEx_InjectedGetValue(&hadc1, RANK_1)
        ib_offset += HAL_ADCEx_InjectedGetValue(&hadc2, RANK_1)
        ic_offset += HAL_ADCEx_InjectedGetValue(&hadc1, RANK_2)
        if calibration_count >= 1000:
            ia_offset /= 1000
            ib_offset /= 1000
            ic_offset /= 1000
            calibrated = 1
        return                          ← 校准期间不跑闭环

    // === 电流采样 ===
    adc_a = ADC1->JDR1                  ← U相
    adc_b = ADC2->JDR1                  ← V相
    adc_c = ADC1->JDR2                  ← W相

    FOC_Get_Iabc(&foc, adc_a, adc_b, adc_c):
        ccr_a = TIM1->CCR1
        ccr_b = TIM1->CCR2
        ccr_c = TIM1->CCR3
        找最大 CCR → 确定重构相
        i_a = (ia_offset - adc_a) × gain_a
        i_b = (ib_offset - adc_b) × gain_b
        i_c = (ic_offset - adc_c) × gain_c
        if max_ccr > threshold:
            重构最大相: Ix = -Iy - Iz

    FOC_Clarke(&foc.state.i_abc, &foc.state.i_alpha_beta):
        i_α = (2·i_a - i_b - i_c) / 3
        i_β = (i_b - i_c) × 0.5774

    // === 观测器电压更新 ===
    MotorApp_UpdateObserverVoltage(&input):
        BoardAdc_GetSnapshot(&snap, &seq):
            读 seqlock 序号
            if 奇数: return 0           ← 正在写
            local = measurements
            if 序号变了: return 0
            *snapshot = local
            return 1

        if 新快照:
            u_abc_measured = snap
            FOC_Clarke(&u_abc_measured, &u_alpha_beta_measured)
            stale_count = 0
        else:
            stale_count++

        if stale_count > 250:
            measured_selected = 0       ← 超时，强制重构
        else if |speed| >= 1200:
            measured_selected = 0
        else if |speed| <= 900:
            measured_selected = 1

        blend_step = Ts / 0.020         ← 20ms 渐变
        if measured_selected:
            weight = min(weight + blend_step, 1.0)
        else:
            weight = max(weight - blend_step, 0.0)

        input.measured_u_alpha = u_alpha_beta_measured.alpha
        input.measured_u_beta  = u_alpha_beta_measured.beta
        input.measured_voltage_weight = weight
        input.vbus = foc.state.vbus
        input.i_alpha = i_alpha_beta.alpha
        input.i_beta  = i_alpha_beta.beta
        input.duty_a/b/c = foc.svpwm.duty_a/b/c  ← 上一拍占空比

    // === 闭环计算（仅 CLOSED_LOOP）===
    if foc_motor_state == CLOSED_LOOP:

        Observer_Run(&foc.observer, &input):
            Observer_RebuildVoltage():
                u_calc_α = Vbus × (2Da-Db-Dc)/3
                u_calc_β = Vbus × (Db-Dc)/√3
                u_α = u_calc_α + w×(u_meas_α - u_calc_α)
                u_β = u_calc_β + w×(u_meas_β - u_calc_β)

            // 磁链积分
            x_α += Ts × (u_α - Rs×i_α + corr_α)
            x_β += Ts × (u_β - Rs×i_β + corr_β)

            // 永磁磁链
            ψ_α = x_α - Ls×i_α
            ψ_β = x_β - Ls×i_β
            ψ_mag = √(ψ_α² + ψ_β²)

            // 径向校正
            error = λ² - ψ_mag²
            corr_α = gain × error × ψ_α
            corr_β = gain × error × ψ_β

            // 角度
            phase_raw = atan2(ψ_β, ψ_α)

            Observer_PLL_Run():
                if psi_valid:
                    ψ_α_n = ψ_α / ψ_mag
                    ψ_β_n = ψ_β / ψ_mag
                    CORDIC(θ_hat) → sin, cos
                    pll_error = -ψ_α_n×sin + ψ_β_n×cos
                    ω_e = PI_RunError(pll_error)
                    speed_rpm = ω_e × 60/(2π×7)
                pll_phase = wrap(θ_hat + ω_e × Ts)

        MotorApp_RunClosedLoop():
            phase_control = wrap(phase_raw)
            q31 = RadToQ31_WrappedFast(phase_control)
            CORDIC_SinCos_FastF32(q31, &sin, &cos)

            FOC_Park(&i_alpha_beta, &sin_cos, &i_dq)

            FOC_Control_Run(&motor_control, i_dq.d, i_dq.q,
                            speed_rpm, vbus, &u_dq.d, &u_dq.q):
                // 速度环（分频）
                if speed_enabled:
                    speed_ref_active = slew(ref, active)
                    if counter >= divider:
                        iq_ref_active = speed_pi.Run(ref, fb)
                else:
                    iq_ref_active = iq_ref

                // 电压限幅
                Umax = Vbus × 0.98/√3
                Ud = id_pi.Run(id_ref, i_d)       ← 限 ±Umax
                Uq_limit = √(Umax² - Ud²)
                Uq = iq_pi.Run(iq_ref_active, i_q) ← 限 ±Uq_limit

            FOC_InvPark(&u_dq, &sin_cos, &u_alpha_beta)
            FOC_InvClarke(&u_alpha_beta, &u_abc)
            FOC_SVPWM_Run(&u_abc, vbus, &timer, &svpwm)

        // === 写 PWM ===
        TIM1->CCR1 = foc.svpwm.ccr_a
        TIM1->CCR2 = foc.svpwm.ccr_b
        TIM1->CCR3 = foc.svpwm.ccr_c

    // === 波形发送 ===
    if just_float_enabled && !console_tx_active
       && CLOSED_LOOP && USART1_TC:
        MotorApp_SendJustFloat(Iu, Iv, Iw, rpm, phase_deg, vbus)
```
