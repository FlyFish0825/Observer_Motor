## 1. 目标与非目标

### 1.1 目标运行路径

~~~text
IDLE 关桥待机
├─ BEMF 可信、沿目标方向   -> FLYING_CATCH -> 平滑接管 -> CLOSED_LOOP
├─ BEMF 可信、沿相反方向   -> 反向同步接住 -> REV_BRAKE -> ...
└─ BEMF 不可信             -> ALIGN -> OPEN_LOOP_IF -> OBS_HANDOVER -> CLOSED_LOOP

CLOSED_LOOP + 反向命令
└─ REV_BRAKE -> REV_PREDICT(有限时间预测角穿零) -> 反向观测恢复 -> REV_HANDOVER -> CLOSED_LOOP
~~~

### 1.2 保留

现有 FOC 电流环、Park/逆 Park、SVPWM、非线性磁链观测器与 SRF-PLL、ADC 采样框架。

### 1.3 明确不做

- 不引入六步换向作为主启动方案。
- 不把未经验证的 HFI / IPD 作为主方案。
- 不在本计划内承诺具体的反转时间指标（缺少惯量、桨叶负载、母线回馈能力数据，见 §4）。

### 1.4 三处必须遵守的架构修正

1. **飞车启动必须取得速度、方向和接管角度**，只做过零测速不够。
2. **PWM 开启时，三相端电压不能当作独立的真实转速证明**；它只能作为电机模型的实测电压输入，
   或与模型估计做一致性检查（且该检查与主观测器共享电压/电流/参数，不能称为独立第二测速器）。
3. **强制角穿零必须有机械响应约束和失败退出条件**；预测角速度变负不等于转子已反转。

### 2.2 断点：闭环不可达

`FOC_MOTOR_CLOSED_LOOP` 在 `Core/` 内**只被读取、从未被赋值**（`git grep` 全量核实）。历史：

| 版本 | 启动入口写入的状态 |
|---|---|
| `653f0f9` 及更早 | `FOC_MOTOR_CLOSED_LOOP` |
| `641ff16`（Step 3）起 | `FOC_MOTOR_ALIGN` → `OPEN_LOOP_IF`，此后无人进闭环 |

后果（可现场复核）：

- 状态机停在 `state=3`(OPEN_LOOP_IF)，`speed_en=0`，`Iq_ref=1.500`（即 `MOTOR_APP_IF_IQ_A`）。
- `motor_protocol.c:52` 的协议状态码只在 `CLOSED_LOOP` 时上报闭环，
  因此上位机永远看到 IDLE。
- `motor_app.c:920` 的 VOFA 波形以 `state==CLOSED_LOOP` 为门控 → 一帧都不发。
- 速度环永远无法使能（仲裁器在 ALIGN / I-f 强制 `speed_loop_enable=0`）。
- `startup.observer_ready` 目前是只写变量，无消费者——它本来就是给接管步骤预留的钩子。

**结论：P1（接管）不是优化项，是本计划的关键路径；在它完成前，本文其余步骤都无法验证。**

## 3. 从代码中核实到的硬约束

| 约束 | 证据 | 对方案的影响 |
|---|---|---|
| 闭环入口无人赋值 | §2.2 | P1 必须优先，否则一切验证无基线 |
| 控制角用的是磁链角 `phase_raw`，不是 PLL 角 | `motor_app.c:155-156` | 接管必须管理 `phase_raw`：`Δθ = wrap(θ_v − phase_raw)`；只平滑 PLL 角无用 |
| PLL 只提供速度，且在快速加速下滞后 21.5° | `pll_kp=400`/`pll_ki=40000`（`foc_math.c:94`）；`α_e=20000rpm/s×2π/60×7=14660 rad/s²`，`sinδ=14660/40000` → δ=21.5° | 不能同时要求快速加速与"PLL 相差<10°"的固定锁定门槛 |
| ALIGN 不运行观测器；IDLE 会复位观测器 | `motor_app.c:250`、`:372` | 待机侦测必须自带角度/速度估计，不能依赖 `foc.observer` |
| 电压源选择按观测器转速 900/1200 rpm 迟滞 | `motor_app.c:300` | 待机阶段观测器转速恒为 0，自动落在"实测电压"分支（正确）；但飞车接管后要重新初始化权重 |
| 端电压融合无 RC 动态补偿 | `motor_app.c:324` | 用带 13.6° 滞后的电压去减本拍 `Ri`、`Li`，模型时间基准不一致 |
| RC 时间常数文档自相矛盾 | doc/03 §148 写 `5.1k×68n ≈ 0.35 μs`，§149 写截止 482 Hz | 名义 347 µs vs 482 Hz 对应 330 µs，差 5%；**必须实测**，不能照抄 |
| Vbus 来自主循环规则组轮询 | `board_adc.c:21`、`motor_app.c:773` | 不能当作有确定响应时间的快速限压链路；制动电流上限必须建立在实测延迟上 |
| **ADC 规则组通道数决定 `ScanConvMode`，进而决定注入序列长度** | V 相事故（`c8a13cc`）；`stm32g4xx_hal_adc_ex.c:1739` | 任何"给 ADC1/ADC2 增减规则组通道"的改动都会静默改变注入 Rank 数；必须配寄存器回读自检（P0-2） |
| ADC2 与 ADC1 共享通道 0~12/14/15 | `stm32g4xx_hal_adc_ex.h:950-975` | Vbus(IN1) 可挂 ADC2 注入组（见 P5-2）；但一旦把 Vbus 移出 ADC1 规则组，ADC1 规则组只剩温度通道 → CubeMX 会把 ADC1 的 `ScanConvMode` 写成 `DISABLE` → **ADC1 的 4 Rank 注入序列（Ia/Ic/U/W）会跟着崩**，必须同时显式固定 `hadc1.Init.ScanConvMode = ADC_SCAN_ENABLE` |
| 速度环斜坡 20000 rpm/s、输出限幅 ±10 A | `controller.h:84`、`:80` | 快反转必须旁路斜坡；±10 A 是软件范围，不是电机/供电能力 |
| 观测器增益为工作值 1e8 | `foc_math.c:83`（`131fca8` 由 5e7 改为 1e8） | 该值承担径向校正，不承担零速起动问题；doc/03:269 仍写 5×10⁷，属过期 |
| 无故障状态、无过流/过压保护状态 | 无 `FOC_MOTOR_FAULT` | 制动与穿零上线前必须先有退流与保护骨架（P0-3） |

## 5. 实施阶段

每步格式：目标 / 只做这些 / 禁止 / 验收 / 回退 / 主要文件。

### P0 可观测性与安全网

#### P0-1 放开波形门控并定义启动期通道

- **目标**：让 ALIGN / I-f / 制动 / 穿零全过程可观测。
- **只做**：把 `motor_app.c:920` 的 `state==CLOSED_LOOP` 门控放开到全部主动状态；
  6 通道定义为 `θ_ctrl, θ_v, θ_obs, Δθ, speed_obs, Iq_ref`（或新增一帧低频 CAN 调试帧承载状态与判据）。
- **禁止**：不在 25 kHz 中断里做字符串打印；不改变控制行为。
- **验收**：I-f 阶段能看到虚拟角与观测角的关系曲线；拔掉上位机不影响控制。
- **回退**：恢复门控条件即可。

#### P0-2 ADC 配置回读自检

- **目标**：把"注入序列被静默截断"变成显式失败。
- **只做**：上电初始化后回读 `ADC1/ADC2->JSQR` 的 `JL` 与 `JSQx`，与预期（ADC1: JL=3 四 Rank；ADC2: JL=1 两 Rank）
  比对；不一致时串口报错并**保持 IDLE**（不 `Error_Handler` 死循环，便于现场诊断）。
- **禁止**：不依赖 `assert_param`（本工程 `USE_FULL_ASSERT` 已关闭）。
- **验收**：人为把 `ScanConvMode` 改回 `DISABLE`，自检必须报错。
- **回退**：去掉自检调用。

#### P0-3 故障状态与退流骨架

- **目标**：为制动、穿零、启动失败提供统一退出路径。
- **只做**：新增 `FOC_MOTOR_FAULT`（或 `START_FAIL`）+ `MotorApp_EnterFault(reason)`（关 MOE、清三相 CCR、
  保留采样与观测）；扩展 `motor_app.c:126` 与 `motor_protocol.c:50` 的状态映射
  （**注意：协议状态码扩展会影响上位机，需同步**）。
- **禁止**：不在故障态里继续输出 PWM。
- **验收**：串口/CAN 能看到故障原因；MOE=0；`run 1` 不能从故障态直接恢复（需 `run 0` 清除）。
- **回退**：删除故障状态分支。

### P1 闭环打通（关键路径）

#### P1-1 ObserverReady 完整化（原计划 Step 5 完整版）

- **目标**：把"3 个条件 + 5 ms"升级为可支撑接管的判据集合。
- **只做**（每条都要可观测）：
  1. 可观测性：估计 BEMF 明显高于测量噪声与模型误差（用 §3.1 的计数表设定下限）。
  2. 磁链幅值在标定范围内且不持续异常（仅必要条件）。
  3. `phase_raw` 与观测转速变化连续、方向一致、无无法解释的跳变。
  4. PLL 相位残差有界，且**考虑当前加速度导致的正常滞后**（δ≈21.5° 量级）。
  5. 电流跟踪无持续失跟、无持续电压饱和（`Ulim`/饱和标志）。
  6. I/f 角差 `Δθ=wrap(θ_v−phase_raw)` 允许非零负载角，但不允许持续失控增长。
  7. 上述条件持续成立且**覆盖至少约 60° 电角度**，并带进入/退出滞回。
- **禁止**：不使用单一转速阈值；不使用不存在的"真实角度误差"。
- **验收**：I-f 正常同步时稳定置位；明显失步或电流饱和时不误报；抖动有滞回。
- **回退**：回退到当前最简判据（`startup.observer_ready` 保持只写）。

#### P1-2 I/f -> 观测器平滑接管（原计划 Step 6）

- **目标**：真正进入 `CLOSED_LOOP`，让闭环可达。
- **只做**：
  - `Δθ₀ = wrap(θ_v − θ_obs)`，`θ_control = θ_obs + Δθ`，按角差与电流裕量决定交接时间，限速平滑让 `Δθ→0`
    （**接管对象是 `phase_raw`**，见 §3）。
  - 交接期间保持电流模式；坐标变化时同步转换电流参考与 PI 电压积分状态
    （复用 `PI_Controller_PreloadOutput`）。
  - 完成后以当前速度初始化速度参考、以当前有效 `Iq` 预装速度 PI，再跟随速度命令。
  - 落实状态切换：在 `motor_app.c:281` 的位置提交 `CLOSED_LOOP`（写在 PWM 之后，边界拍仍用原状态量）。
- **禁止**：不把 PLL 角当控制角；不在接管瞬间放开速度环。
- **验收**：接管瞬间三相电流无明显尖峰；`θ_control` 连续；dq 电流不因坐标切换突然旋转；速度环投入时 `Iq` 不跳变；**正反两个方向都通过**。
- **回退**：`git revert` 本步；状态机回到"停在 I-f"。

#### P1-3 启动上限与失败退出

- **目标**：1000 rpm 仍不可信时有界处理，不强行宣布成功。
- **只做**：到 1000 rpm 后进入有界验证窗口（时间上限），仍不 ready 则退流 → 故障/待机，并记录失败原因。
- **验收**：故意用错误相序或过大负载，必须走失败路径而不是持续拖转。
- **回退**：延长验证窗口或退回 I-f 保持。

### P2 静止启动硬化

#### P2-1 定位电流缓升与双角定位

- **只做**：2~3 ms 建立定位电流；两个相邻定位角或小角度缓扫后停在最终角；总预算 20~40 ms（待标定）。
- **禁止**：不把 5~10 ms 写成先验保证；不用加大电流代替机械收敛时间。
- **验收**：不同初始转子位置都无不可控电流冲击；定位角控制连续；STOP 立即退出。

#### P2-2 I/f 加速度受约束

- **只做**：按 `J_eq·α_m + T_load < K_t·I_start·cos δ_allow` 反算允许加速度；把该不等式写成代码注释与验收条件。
- **禁止**：不通过调快频率斜坡并指望电流环"拉住"转子。
- **验收**：正反方向都能稳定拖起且电流不持续饱和；记录实际加速时间与所用电流。

### P3 电压输入一致性（互补电压重构，原计划 Step 15 前置）

#### P3-1 离线标定

- **只做**：标定三路比例/偏置/相序/角度正方向；实测 τ 与处理延迟；标定死区/管压降系数；
  确认 doc/03 的 RC 描述（0.35 µs 与 482 Hz 矛盾）以实测为准。
- **验收**：关桥带转时，实测端电压的幅相与理论 BEMF 在 1000 rpm 处吻合到 ±3° 以内。

#### P3-2 在线接入

- **只做**：`u_obs = u_measured + u_pwm,comp − H(u_pwm,comp)`，α/β 分别计算；`H()` 模拟实板 RC；
  定义与现有 900/1200 rpm 权重的共存/替换策略；**飞车接管时正确初始化滤波器状态**，避免短暂重复叠加 BEMF。
- **禁止**：不对 ADC 电压做高增益微分；不在滤波器状态未初始化时切入。
- **验收**：静止/低速/额定三点上 `u_obs` 与 `u_meas` 幅相一致；1000 rpm 处相位滞后由 13.6° 降到 ±3° 量级。

### P4 待机 BEMF 侦测与飞车接管（原计划 Step 7/8/9）

#### P4-1 IDLE 后台侦测

- **只做**：在 IDLE 维护 `角度、带符号转速、BEMF 幅值、可信度、更新时间`；
  用三相去共模后的 αβ 矢量（复用 `FOC_Clarke`）计算角度与其变化；过零顺序交叉检查；
  `θ_r ≈ atan2(e_β,e_α) + arctan(ω_e·τ) − sgn(ω_e)·π/2`，并补偿实际处理延迟。
- **必须排除**：相电流未充分衰减、端电压削顶、整流失真、噪声过大。
- **禁止**：IDLE 中不让观测器的异常角度参与控制；不把 PWM ON 的端电压过零当转速证据。
- **验收**：外部带动时方向/转速/角度与独立基准一致；低于可信阈值时可信度正确下降。

#### P4-2 同向飞车接住

- **只做**：用实测角度/速度初始化观测器 → 小 Iq 同步接住 → P1-1 判据 → 复用 P1-2 接管。
- **验收**：多个初始转速均可接住；接管电流冲击受控；不出现角度跳 180° 或相序错误；低可信度时退回静止启动路径。

#### P4-3 反向飞车接住（只做到接住）

- **只做**：按实际旋转方向同步接住，进入受控闭环；**不做快速反转**。
- **验收**：正命令下遇到反向带转，不会施加错误角度的大转矩。

### P5 主动制动与母线约束（原计划 Step 10/11）

#### P5-1 闭环主动制动

- **只做**：旁路速度斜坡与速度 PI，按允许 `di/dt` 建立负 `Iq`；观测器可信时继续用观测角闭环制动；
  不交换相序、不把角度加 π、不在零速处再次翻转 `Iq` 符号。
- **验收**：+1500 rpm 可重复平稳制动到设定低速；−1500 rpm 对称；`Iq` 变化率受控；记录 Vbus 上升曲线。

#### P5-2 母线回馈约束

- **只做**：量化 Vbus 轮询最坏延迟；按 `ΔE_C = ½C(V_new²−V_old²)` 与允许电压上升速率确定限流/卸能要求；
  必要时把 Vbus 迁到 **ADC2 注入 Rank3**（ADC2 支持 IN1，已核实），实现 25 kHz 同步采样——
  **同时必须显式固定 `hadc1.Init.ScanConvMode = ADC_SCAN_ENABLE`**（见 §3 倒数第二行），并同步 `.ioc`。
- **禁止**：在惯量、桨叶负载、供电回馈能力未测前提高制动电流追求更短反转时间。
- **验收**：不同转速/负载下 Vbus 不超过定义的安全范围；Vbus 上升时制动命令按预期降低；硬件过压保护为最后防线。

### P6 预测角穿零与反向恢复（原计划 Step 12/13/14）

#### P6-1 旁路预测器

- **只做**：observer 可信时记录最后可信角/速度/`Iq`/实测减速度趋势；用
  `ω̇_m = (K_t·Iq − T̂_load)/J_eq`、`θ̇_e = p·ω_m` 后台预测并与可信区数据对比；
  首版用等效惯量 + 分速度段负载模型，不上复杂机械观测器。
- **禁止**：不沿用制动前段恒减速度外推（近零速水阻协助显著减小，会预测过早穿零）。
- **验收**：预测角误差随时间的增长规律可测，得到适合本电机+桨叶+水负载的初值。

#### P6-2 真接管穿零

- **只做**：`θ_control` 切到连续预测角，保持反向 `Iq`；误差预算
  `ε_θ(t) ≤ ε_θ0 + ε_ω0·t + ½ε_α·t²`，首版以约 30° 电角度 + 最大时间作为**双退出条件**；
  退出即退流并回到重新侦测/捕获。
- **禁止**：把 `ω_pred<0` 当作真实已反转；用 PWM ON 端电压过零作为反向证据。
- **验收**：有明确超时与失败退出；退出后不残留错误控制角。

#### P6-3 反向观测恢复判据

- **只做**：反向运动重新具备可观测性后，方向正确、磁链幅值回到有效范围、与预测角关系合理、
  电流跟踪正常，且条件持续成立。
- **验收**：反向低可信阶段不让异常角度影响控制；不"每拍把观测器贴到预测角再把一致当锁定证据"。

#### P6-4 反向平滑接管

- **只做**：复用 P1-2 的角度偏置渐消路径完成预测角 → 反向观测接管。
- **验收**：`+1500 → −1500` 与 `−1500 → +1500` 分别通过；接管瞬间无电流尖峰。

### P7 全链路验收

| 场景 | 通过标准 |
|---|---|
| 双向静止启动（含水中不同初始位置） | 无冲击、可重复、成功率记录 |
| 双向飞车接住（多转速点） | 接管电流冲击受控、不误判方向 |
| `+1500 → −1500` 与反向对称 | 预测角误差、真实过零时刻（独立基准）、重新锁定时间全部记录 |
| 外部水流带转工况 | 不误锁、不反向冲击 |
| 不同母线电压 / 水温 / 负载 | 结果一致性 + 安全边界 |

|---|---|---|

| 观测器增益 1e8 为工作值 | 已提交，非基线 | 明确它不承担零速起动；若调整需单独标定并记录 |
