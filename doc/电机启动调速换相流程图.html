命令/通信 启动定位 I/F 开环 观测器接管 闭环运行 停机/故障
这里的“换相”不是六步换相。 当前是 FOC：通过连续变化的电角度 theta_ctrl 做 Park / 逆 Park， 让定子电压矢量持续旋转。启动时角度来自 startup.if_angle， 接管时为 phase_raw + handover_offset，闭环后直接来自磁链观测器 foc.observer.state.phase_raw。

1. 从“收到命令”到电机真正开始输出

通信域只写“意图/目标”；真正开桥由主循环门控，真正控制输出由 ADC 注入中断每拍完成。
① 收到速度 / Run 命令 CAN：MotorProtocol_HandleRx() → MotorProtocol_SetRun()
速度目标：motor_control.speed_command_rpm；同时置 speed_ref_rpm，并调用 FOC_Control_EnableSpeedLoop(...,1)
run = 1
② MotorApp_RequestRun(1) 写 motor_run_command=1 → MotorApp_ApplyRunCommand() → 无故障闭锁时得到 motor_run_requested=1。这里还没有启动 PWM。
主循环
③ MotorApp_Process() 启动门控 必须同时满足：run requested、无 fault latch、ADC 注入配置有效、电流零偏已校准、 motor_idle_reset_done=1、当前 FOC_MOTOR_IDLE。
④ MotorApp_StartControlSequence() 校验 speed_command_rpm / Ts / 极对数 / Vbus； 重建 startup，确定方向；设置 I/F 目标；状态切到 FOC_MOTOR_ALIGN；最后 FOC_PWM_Start()。
ALIGN = 30 ms Id = 1.0 A I/F Iq = 1.5 A 强制开环阈值 = 800 rpm 接管目标 = 1000 rpm
进入 25 kHz 控制循环
⑤ MotorApp_OnInjectedConversion() 每 40 μs 执行一次 ADC 电流采样 → Clarke → 观测器输入 → 推进启动状态机 → 解析本拍 theta_ctrl / Id_ref / Iq_ref → 电流环 → 逆 Park / 逆 Clarke → SVPWM → 写 TIM1 CCR1/2/3。

2. 启动状态机：角度源是如何从“虚拟角”交给“观测角”的

这四个状态决定了换相角来自哪里，也决定此时是定位、强拖还是闭环调速。

ALIGN

固定电角度 0 rad

theta_ctrl = 0

Id_ref = 1.0 A

Iq_ref = 0

持续约 30 ms，把转子拉到已知方向；此阶段不跑观测器。

OPEN_LOOP_IF

虚拟角强拖

theta_ctrl = startup.if_angle

虚拟速度按受限斜坡推进，角度采用梯形积分：

if_angle += 0.5·(ωprev+ωnext)·Ts

Iq 提供转矩；目标先到 min(|cmd|,1000 rpm)。

OBSERVER_HANDOVER

平滑接管角度

theta_ctrl = phase_raw + offset

offset 用 smoothstep 从初值渐消到 0，接管时间约 20–150 ms。

每拍旋转 d/q 电流 PI 积分器，避免换坐标系时电压矢量突然转向。

CLOSED_LOOP

观测器角度换相

theta_ctrl = phase_raw

速度反馈：speed_rpm_f

速度 PI 产生 Iq 目标，电流 PI 产生 Ud/Uq，连续 FOC 换相。

首次接管后还有约 50 ms 的启动淡入/限斜坡阶段。

OPEN_LOOP_IF 什么时候允许进入 OBSERVER_HANDOVER？
MotorApp_UpdateObserverReady() 负责判定。当前源码要求观测器连续稳定一段时间， 同时检查速度、磁链、电流跟踪等条件，并要求累计覆盖一整圈电角度。核心参数包括： Ready 连续时间 30 ms、最低观测转速 800 rpm、速度匹配误差 40 rpm、净电角度覆盖 2π。 若目标绝对值 ≤ 800 rpm，则 forced_open_loop=1，保持 I/F，不让观测器参与控制角。

3. 闭环调速链：转速命令最后怎样变成电机转矩

速度参考在 25 kHz 每拍平滑推进；速度 PI 本身默认 1/25 分频执行，即约 1 kHz。

3

PLL 得到电角速度，再换算机械 speed_rpm / speed_rpm_f。

4

闭环时 phase_raw 直接成为下一拍 FOC 控制角，形成连续电子换相。

为什么角度一变，相电流就“换相”？

1

Park 把采样电流投影到“随转子旋转”的 d/q 轴。

2

PI 在 d/q 轴上算出所需电压矢量 Ud/Uq。

3

逆 Park 使用同一个 theta_ctrl 把电压矢量旋回定子 α/β 坐标。

4

SVPWM 将这个连续旋转的电压矢量变成三相占空比，因此无需离散“六步换相表”。

5. 运行中调速与反向：当前代码真正走的路径

同向改速和反向不是同一条逻辑。反向必须跨过低速观测盲区，所以会主动从闭环退回 I/F。

同方向改变转速

1

新命令写入 speed_command_rpm。

2

CLOSED_LOOP 中将它交给 speed_ref_rpm。

3

speed_ref_active_rpm 按 slew 平滑向新目标移动。

4

速度 PI 改变 Iq，Iq 改变转矩，电机加/减速；换相角仍来自 phase_raw。

正转 ↔ 反转 / 进入低速区

1

检测到新命令方向与当前 startup.if_direction 相反，置 closed_loop_braking=1。

2

闭环阶段内部把 speed_ref_rpm 暂时设为 0，先用观测器角度制动。

3

只有原始与滤波观测速度都进入 ±800 rpm，才调用 MotorApp_BeginForcedOpenLoop()。

4

继承当前观测角、速度、实测减速度和 Iq，切到 OPEN_LOOP_IF，虚拟速度连续穿过 0。

5

若最终 |目标| ≤ 800 rpm：继续强制 I/F；若目标更高：拉到接管点 → Observer Ready → HANDOVER → CLOSED_LOOP。

6. 停机 / 故障路径

速度命令 = 0 或 Run = 0 主动状态中 command==0 会立即清 MOE、清 run 标志并回 IDLE； Run=0 也会使中断入口回 IDLE，随后统一执行安全复位。
IDLE 安全复位 停 TIM1 CH1~3 / 互补输出、CCR1~3=0，FOC_Control_Reset() 清 PI 运行状态， 观测器/控制缓存恢复为下一次启动的干净起点。
非有限值 / Vbus 非法 / 启动超时 / Observer 未就绪 MotorApp_EnterFault(reason)
立即撤销 MOE + fault latch 记录首个故障快照，motor_run_requested=0，状态回 IDLE；显式 Run=0 才解除闭锁。
